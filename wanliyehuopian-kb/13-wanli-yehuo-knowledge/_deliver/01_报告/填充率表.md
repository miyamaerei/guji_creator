## 11. 低填充字段原因汇总（SKILL.md §10 要求）

| 层.字段 | 填充率 | 原因 |
|---|---|---|
| `ents.exam_info` | **5.2%** | 科举信息只在原文**明确提到科第**时才有（如「嘉靖二十六年进士」）；本书 70%+ 内容为朝章典故，人物出场常不带科第。**非缺失，是原文约束**。可从 ○科场 门类 110 条定向回填。 |
| `events.summary` 等 style B 扩展字段 | **8.3%** | 仅新补卷（16–34）采用 style B；卷01–17 用 style A。属**双 schema 并存**，见使用报告 §6.2。 |
| `appts.faction_implication` | **3.5%** | 只在原文明确点出党争牵连时填。**宁缺毋滥**：不推断、不外推。 |
| `appts.concurrent_posts` | **2.9%** | 「兼领」情形本身少见。 |
| `cits.quoted_text` | **28.5%** | 引书多为泛引/暗用，原文无成句引文可摘。 |
| `opns.historical_parallel` | **15.6%** | 沈德符只在少数条目标明历史类比。 |
| `tmes.related_org` / `related_evo` | 4.8% / 3.1% | 跨机构/跨沿革关联需原文同时提及两条制度，样本稀少。 |
| `tmes.era_order` | 2.2% | 仅新 schema（66 条）回填。 |
| `regs.abuses_reform` | 11.5% | 只在原文明确论及「弊端与改革」时填。 |
| `regs.tme_ids` | 10.4% | 需同一条目内出现制度沿革记录才可关联。 |
| `rels.faction` | 0.2% | 党派信息主要在 `ents.faction` 与 `opns`，本层只个别标注。 |

**结论**：**10 层均无零填充字段**；全部低填充字段均可归因为
①**原文约束**（原文未提供该信息） ②**双 schema 并存**（新字段只在 style B 记录上）
③**宁缺毋滥的标注纪律**（不推断）。无一是生成器漏填。
