## 3. 切分规则（对齐 SKILL §2）

1. **条边界**：原文 `【标题】` 行为新条起点；标题原文保留进 `original`（含 `【】`）。
2. **正文多段**：段间以 `\n` 连接（供数据层卷二~卷十复合条 `NN-NNN-SS` 子则拆分）。
3. **相邻标题合并**：两标题相邻且无各自正文、共享一段正文 → 合并为单条，两标题并列保留。
4. **脚注行**：以 ① 等圈码开头的行为脚注，**保留归所属条**。
5. **纯数字行**：分页页码类（如 `0`、`1`），**剔除**并登记于 `base_report.dropped_page_lines`。
6. **00 卷锚点提取**：丛书总序 / 导读 / 点校说明 / 原序 / 四库提要，共 5 条；锚点连续、版本行不并入正文。

## 5. 归一（norm）规则（对齐 SKILL §2）

- 缺字 `☐`（U+2610）→ `□`（U+25A1）；其余原样保留（`VARIANT_MAP` 后续在数据层扩展）。
- 文本去两端空白、行内 `\r`；**不改标点、不简化繁体、不处理异体**（数据层逐层做语义归一）。
- 重文号：源无 々/〻 出现，本条规则预留。
