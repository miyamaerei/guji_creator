# 《平平言》卷一~卷四 白话文翻译规格

> 本规格与三篇样例（`白话文\序_白话.txt`、`白话文\凡例_白话.txt`、`白话文\跋_白话.txt`，已由组织者完成）共同构成翻译标准。动手前先读样例文件，体会序跋体的译文风格与行文节奏。

## 一、目标文件结构

每卷译文写入 `E:\git\ToolBox\guji\pingpingyan-kb\白话文\<篇名>_白话.txt`，结构如下（逐行对应）：

```
【平平言卷X】           ← 第1行：照抄原文第1行【篇名】，不翻译
（卷首篇目）            ← 固定标记行
巴陵方大湜菊人著       ← 照抄原文作者行，不翻译
<卷首篇目条目>          ← 照抄原文目录条目，一行一条，不翻译（84/87/43/70 条）
（正文）                ← 固定标记行
○标题                  ← 照抄原文 ○ 开头的标题行（含 ○ 符号），不翻译
<该节译文段落>          ← 该节正文的译文
○标题
<译文段落>
……
```

## 二、翻译规则

1. **○ 标题行**：逐字照抄原文（含开头 ○ 符号），独立成行，一个不能丢。
2. **正文段落**：逐段翻译为通顺的现代汉语（简体字），一段原文 = 一行译文，顺序一一对应；不合并、不拆分、不省略、不跳段。
3. **人名 / 官名 / 年号年份 / 书名 / 机构名**：保留原文，可加简短括注。例：`呂新吾先生【坤】` → “吕新吾先生（坤）”；`光緒四年` → “光绪四年（1878）”；`胡文忠公【林翼】` → “胡文忠公（林翼）”。
4. **正文夹注【…】**：人名、字号、书名、年代等保留并括注；夹注若是整句解释或引文（如 `【如講喫講穿講排場講徵逐講鑽營講做官全仗門丁之類皆邪說也】`、`【武德二年詔自今正月五月九月不得行刑…】`），并入译文句子译白。
5. **引述前人言论**（吕新吾、汪龙庄、刘廉舫等前贤的议论）：照常译白，不算条目。
6. **无标记的子目 / 条目行**（书目条目、律例条文、章程条文）：
   - 短条目（书名+【注】或单独书名，如 `實政錄【明呂坤叔簡撰】`、`大清會典`、`邸鈔`、`捕蝗要訣`）：照抄原文，可附一句简短括注（如 （《实政录》，明代吕坤撰，官箴书））。
   - 长律例/章程条文（如 `侵盜律載…`、`那移律載…`、`公罪該笞者一十…`、`級紀抵銷…`）：照抄原文，可在末尾加（律文）/（则例）等极简括注，不翻译。
   - 条目块中的说明性段落（如 `辦案靠幕友審案則全靠自己…`、`以上各書所錄皆…`、`一部處分則例無非公私罪名…`）：按正文翻译。
   - 原文跨两行的条目（如 `授時通考【乾隆二十二年` + `敕撰】`）：两行都照抄，保持原样。
7. **卷首篇目**：照抄不翻译（目录性质）。

## 三、风格与示例

**示例一（○节正文，卷一第一节）：**

原文：`○造福莫如州縣`
原文正文：`士君子心存利濟不能為督撫即須作州縣…切不可妄自菲薄`
译文（一行）：士君子心里存着利人济物之念，如果不能做督抚，就必须做州县——因为督抚接近君主，州县接近百姓。然而兴利除弊，不只是藩臬道府能说不能行，就是督抚，也不过托之空言；只有州县，才真正见之于行动。所以造福莫如州县。前明章枫山先生（懋）由翰林贬为临武知县，还没上任，又改任南京大理寺丞，曾叹息说：我恨不能做临武知县！因为知县正好做事、正好救百姓，岂能以官小为嫌呢？枫山本是理学名儒，尚且以不做知县为恨事，可见宰官一身，众生托命。果真能事事存心、时时留意，必能造福百姓。你们如若有命做州县，切不可妄自菲薄。

**示例二（子目块，卷一候補宜讀書节）：**

- `經史`（组目小标题）→ 照抄。
- `厯代名臣言行錄【戰國至五代十國國朝朱桓拙存編輯…】` → 照抄（可括注（书目））。
- `古人引經斷獄者不一而足…`（说明段）→ 翻译，如：古人引用经书断案的，不止一个两个。一旦做官，虽不能像经生那样终日诵读，但偶尔翻阅，总有好处。因为少年时读书全无体贴，不过囫囵吞枣罢了；经历了世事之后，再读旧书，便觉得亲切有味。史书无事不有，更可以增长见识。
- `以上各書所錄皆嘉言懿行讀之可以瀹心性鼓精神`（收束段）→ 翻译，如：以上各书所录，都是嘉言懿行、丰功伟绩，读了可以陶冶心性、鼓舞精神。

## 四、写作与落盘要求

1. 译文必须完整写入文件才算完成，禁止只留在对话里不落盘。
2. 原文较长（1.7万~2.3万字），可分多次追加写入（如每次 60~80 段），但必须完整写完。
3. 写完自查：
   - a. 译文非空行数 ≥ 原文非空行数（数值见下表）；
   - b. 原文全部 ○ 标题逐字出现在译文文件中（可用脚本比对）；
   - c. 抽查首、中、尾若干段，确认无遗漏、无截断。
4. 交付时报告：文件绝对路径、译文非空行数、○ 标题数、自检三项结果。
