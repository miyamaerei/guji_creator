## 3. 层 schema（启用 9 层 + 底座）

### 3.0 底座（L0）
```
item_id: NN-NNN            # 卷-序，全书唯一
original: <原文全文>        # 打包器从 _item_registry.json 注入，AI 不手抄
norm: <归一后文本>          # 繁简/异体归一，缺字保留原形
```

### 3.1 实体层 ent（ENT-）
```
ent_id: ENT-NNNNN          # 跨卷去重主键
item_id: NN-NNN
text: <原文词形>
type: <ENTITY_TYPES 20 值>  # 本书启用子集：person/official/institution/place/era/work/object/doc/system/behavior/punishment/quantity/unknown
start/end: <词形在 original 中的偏移>
normalized: <归一后规范形>
confidence: high/medium/low
source: <词形出现的条目/卷>
```

### 3.2 职官任职层 appt（APPT-）
```
appointment_id: APPT-NNNNN
item_id: NN-NNN
person: <人名>
person_ent_ids: [ENT-…]    # 引用实体主键
office: <官职>
official_ent_ids: [ENT-…]
institution: <衙门/机构，可空>
institution_ent_ids: [ENT-…]
when: <任年/年号纪年，如"万历十八年任">
status: <APPT_STATUS 12 值>  # 现任/致仕/升迁/贬谪/罢黜/兼领/暂代/追赠/未明/起复/世袭/举荐
evidence: <文中依据要点>
original: <原文注入>
confidence
```

### 3.3 事件层 evt（EVT-）
```
event_id: EVT-NNNNN
item_id: NN-NNN

who_ent_ids: [ENT-…]
action: <动作短语>
what: <事件内容要点>
when: <纪年/相对时间>
where: <地点>
original, confidence
```

### 3.4 文献资产层 lit（LIT-）

## 6. 执行期坑注（本书特有）

1. **志遗卷 △ 诗文作者标题（72 个）**：一作者一标题一条（题名+诗文全文），LIT 为主、NAM 登记作者名录、APPT 登记明示官职；作者官职括号内已注（如"大学士，淳安人"）直接入 APPT/NAM entries。
2. **卷三职官为单一 ○ 标题**：下含知县/县丞/主簿/典史历任多段（无标题符号），**仍为一条**（03-001），NAM entries 数组化登记全部历任 + APPT 逐人拆条。
3. **历朝宣谕**：卷一宣谕一条内含祖制说明 + 历年全文 + 按语，LIT 按"某年宣谕"拆多条共享 item_id；作者按语入 OPN。
4. **碑记全文（卷二十敕撰）**：一篇一 LIT（title=碑记名、author=撰者），营造事件按文中年月拆 EVT。
5. **原文一段一行 + ○/△ 标题行**：切分以标题行为条目起点，正文（段）归其下；卷首【卷N】行与空行跳过。
