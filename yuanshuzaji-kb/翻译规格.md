# 《宛署杂记》白话文翻译规格（逐卷）

明·沈榜《宛署杂记》（万历年间宛平县地方志，自序 + 卷一至卷二十）。本规格为全部翻译子任务的统一基准，必须逐条遵守。

## 一、输入与输出

- 输入原文：`E:\git\ToolBox\guji\yuanshuzaji-kb\原文\<卷名>.txt`（UTF-8 无 BOM，一个段落占一行，行尾 CRLF）
- 输出译文：`E:\git\ToolBox\guji\yuanshuzaji-kb\白话文\<卷名>_白话.txt`（UTF-8 无 BOM）
- 卷名取值：自序、卷一、卷二、……、卷二十（中文数字）。**只许翻译，不许改动 `原文\` 目录下的任何文件，也不许改动任何拆分/核验脚本。**

## 二、格式要求（逐条强制）

1. 译文文件第 1 行 = 原文的【卷名】行，原样保留（如 `【卷一】`），不翻译；随后保留一个空行，与原文结构一致。
2. 所有以 `○` 或 `△` 开头的分节标题行：**原样复制进译文，不翻译**。这是原书章节标题（如 `○宣谕`、`△内府`、`△敕谕`）。原文全卷共 165 个 `○`/`△` 标题，一个都不能丢。
3. 正文段落逐段翻译，**一段原文对应一段译文，各占一行**（不要在一个段落中间手动换行，除非原文本身换行）。
4. 原文行中若嵌有 `○`/`△` 小标题（如某行行中出现 `△敕撰`），译文中可将其独立成行、原样保留，再续译其后文字。
5. 原文中的空行，译文在相同位置保留空行。
6. 结尾落款/日期行（如 `万历壬辰人日，书于宛署之见日堂`）也按正文翻译成白话。

## 三、翻译口径（用户在《吕公实政录》项目验收过的标准）

- 叙述性文字：译成通顺现代汉语。语序调整、省略补齐、句读理顺，不逐字硬译，不文白夹杂；不得漏译整句或整段。
- 专名与数字：人名（历任知县、县丞、主簿、典史等）、官名（顺天府府尹、巡按御史等）、年号年份（正德、嘉靖、万历某年）、地名街道坊巷、机构名（文书房、会极门、承天门等）、寺庙祠观名、钱粮银两数字（两/钱/分/厘/毫）、田亩数目——**保留原文**，不必强行改写或音译；必要时可加括注（如"冯保（司礼监太监）"）。
- 忠实原意：不添加原文没有的史实，不删减内容；每段译文长度与原文相当或更长，通常不低于原文的一半。
- 公文、敕谕、碑记类段落（卷二十、卷十五等）：骈散句译白，但其中的官职、人名、年月、钱粮、工程尺寸等硬信息必须保留。
- 原文中的罕见/缺损字符（如 `■〈忄雙〉`）：按文意译出即可，不必照抄。

## 四、落盘方式（强制）

- 必须把整卷译文**完整写入输出文件**才算完成；禁止只把译文留在对话里不落盘。
- 用 Write 工具整文件写入；超长卷可分多次追加：追加命令必须是
  `[IO.File]::AppendAllText($path, $text, (New-Object System.Text.UTF8Encoding($false)))`
  （UTF-8 无 BOM）。
- **编码红线**：本机 PowerShell 5.1 的 `Out-File`/`Set-Content`/`Add-Content` 默认编码会损坏中文，禁止不带 `-Encoding` 使用它们；也禁止 ANSI/GBK 写入。写完后可抽查字节头不是 EF BB BF 且可正常 UTF-8 解码。
- 行尾用 LF 或 CRLF 均可（组织层最后统一为 CRLF），不影响验收。

## 五、交付前自检（每个卷都必须做，通过才能报告完成）

1. 行数检查：译文文件行数 ≥ 对应原文文件行数（用 `(Get-Content '<路径>' -Encoding utf8).Count` 数行）。
2. 标题检查：原文中所有以 `○`/`△` 开头的行，必须逐字出现在译文文件中（读入两个文件全文做字符串包含比对，不能只靠目测）。
3. 完整性检查：译文最后一行应对应该卷原文最后一行的译文；逐段核对没有漏段、没有截断。
4. 报告内容：每个输出文件的绝对路径、行数、保留的 `○`/`△` 标题数、三项自检结果。
