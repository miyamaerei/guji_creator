## 1. 启用层枚举

### 1.1 实体类型 ENTITY_TYPES（继承基准库 18 值；本书高频子集 + 兜底）
```
person 人物（正：人名实体；反：职官名归official）
official 职官（别名：office；正：尚书/巡抚；反：机构名归institution）
institution 机构（别名：org；正：吏部/内阁/镇抚司）
place 地名（正：京师/福清/镇东卫；反：抽象方位归other/unknown）
era 年号朝代（正：嘉靖/万历/天启）
work 文献书名（别名：book；正：《神惠记》《光庙实录》）
posthumous 谥号（正：文忠/文懿/文肃）
unknown 类型待定（兜底：拒识优于乱识）
（基准库其余值 object/animal/plant/food/doc/system/behavior/punishment/time/quantity 按需启用，执行期校准）
```

### 1.7 奏疏谕旨互动类型 MEM_TYPES（**本书归纳增量**，封闭+兜底）
```

使用说明：
上疏=臣下正式具疏（正："具疏乞休""再疏辞""连疏求去"；反：非正式揭帖归"具揭"）
具揭=臣下密揭/揭帖（正："具揭言其不可""具揭申请"）
条陈=臣下列条陈奏（正："条陈时弊""条陈要务"）
谕旨=皇帝主动下发谕旨（正："上传谕内阁""特谕卿知"；actor=皇帝，非回应性质）
批答=皇帝对疏揭的批复（正："得旨：……""奉圣旨：……"）
传谕=中使/文书官传达上谕（正："遣文书官传谕""中官传谕"）
面奏=当面奏对（正："面辞金台""御前面奏"）
```

### 1.8 奏疏谕旨互动结果 MEM_RESULTS（**本书归纳增量**，封闭+兜底）

```
未报=无批答/不报（正："不报""疏上，久寝"）
```

## 2. 枚举治理约定

- 单点文件 `_kg_enums.py`（实例自包含，固化上述快照）；文档（本文件）与代码口径一致，validate 比对。
- 执行期出现未匹配值 → 打包器收集入 pending 表（不报错终止）→ 卷/片结束输出枚举使用分布 → 批处理决议（新增/归并/改名，新增必须有实例证据）→ registerVersion+1 → 回溯存量（dry-run 再 commit）→ 更新本文件与基准库。
- 兜底值永远保留；可归类的不得用兜底。
