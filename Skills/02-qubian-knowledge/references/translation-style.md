# 《蘧编》翻译风格基准（TRL）

> 风格基准：**余光中风格**（用户 2026-10-10 固化，与《水东日记》《五杂俎》同基准），按本书内容调整示例。
> 适用：C5 古今翻译层全量 71 条（卷 01–20）；卷 00/21/22 不入层不译。

## 1. 七条规范

1. **译原意不译原字**：以句意为准，防死译（正："余前有二母"→"在我之前，父亲已有两位夫人"；反：逐字直译"余/前/有/二母"）。
2. **主从改并联**：长句拆成身份相当的短句串连，顺应中文句法（正：把"太夫人将娩，适避倭至外家，族人以俗忌不乐"拆为"太夫人临产，恰好避倭躲回娘家；族人因风俗忌讳不高兴"）。
3. **白以为常文以应变**：白话为骨干、文言作调剂（"蒙允""引罪求去"等可保留文言色彩，正文以白话为主）。
4. **精简防冗余**：删多余字句，忌"……之一""进行""当……时"式翻译腔。
5. **善用四字格**：自然不造作（"颠沛流离""辞不获命"）。
6. **忌翻译体公式**：不套"据悉/然而/与此同时/众所周知"。
7. **专名保留+括注**：人名、职官、地名、年号、书名保留原词，首次出现加括注（职官术语符合明史口径：如"南太宰"括注"南京吏部尚书"）。

## 2. 本书专名处理示例

| 原文 | 译文处理 |
|---|---|
| 先少师公 | 保留"先少师公"，括注〔叶向高之父叶朝荣〕 |
| 南太宰 | "南京吏部尚书（南太宰）" |
| 得旨/奉旨 | "皇帝批复说"／"奉旨"保留 |
| 余 | 译为"我"（第一人称自述，叶向高本人） |
| 化北里/平北里 | 保留地名原词 |

## 3. 长文翻译（谕旨/奏疏/婚牍）

- 分句群翻译保留分段；一段原文→一段译文（可合并短句群）。
- 皇帝谕旨按"君上口吻"译，保持诏令庄重；臣下疏揭按"臣下语气"译。
- 缺字（☐/□）按 norm 处理：无法补者译文标注"（原文缺字）"。
- 专名括注仅首次出现；重复出现不再括注。
