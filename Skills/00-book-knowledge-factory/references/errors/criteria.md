## 一、接线五步（照抄不发挥）

```

④ 每个 build_*.py 结尾调用 run_guardrails()，输出  OK <层> ERR=N GAP=M

```

**护栏不得静默删除**：凡不适用本书的装置，须在实例 SKILL.md **写明理由**。

## 二、A 族｜静默失败——「没有报错 ≠ 有数据」

- [ ] 凡扩展字段已登记进 `FieldCoverage(fields=[...])`；**填充率表与 ERR/GAP 并列交付**。
- [ ] 零填充字段已按**固定顺序**排查：**① 回填器是否真被 `build_*` 调用 → ② 解析覆盖面是否漏组（复合句只取首组）→ ③ 原文是否真没有**；③ 须**显式登记原因**（`zero_explanations`），不得沉默通过。
- [ ] 「某层 0 条 / 覆盖率异常偏低」已逐个给出解释，**无沉默通过项**。
- [ ] **自检已跑**：`python <骨架目录>/self_test.py` → `PASS 24 / FAIL 0`。
      > 护栏自身也是代码，也会坏。骨架首轮自检即抓出 4 个真缺陷（dict 迭代解包崩 / `assert_unique_ids` 返回类型错 / `merge_shared_json` 传 dict 崩 / **`cn2int("洪武三年")` 返回 0**）。
      > **实例若改动了骨架任何函数，必须重跑自检。**
- [ ] 若为骨架/校验器**新写或修改**了把关者：已配**功能自检**，且自检验的是「**遇坏数据会不会响**」（正反例各一），不是「函数能 import」。
- [ ] **自检的被测对象形状与生产声明逐字一致**——测试替身只许替换「**数据内容**」，**不许替换「容器的类型 / 形状 / 键名」**。

> **反例留档**：#45 `salary_ref` 431/431 全空而 ERR=0｜#56 `_seal_backfill.py` 写完未被调用，`seal` 填充 0 而 ERR=0（**同坑第 2 次复发**）｜#55 印信表复合句只取首组，覆盖 57% 不报错｜#62/#63 护栏与自检自身失效。

## 三、B 族｜命名即契约——「四处同源，一处声明」

- [ ] 目录名 / 文件名前缀 / 索引槽位名 / schema 键名**四处同源**，**只由 `LAYER_SPECS` 声明一次**；`check_naming_consistency()` 通过。
- [ ] 源数据**只写槽位**，**无手写业务 ID**；ID 序号取**记录全局序号**（不是 `slot`）。
- [ ] 子节点 ID 走 `assign_child_ids()`，**保留已有 ID**（防两个遍历器互相覆盖）；同名对象可按 `org_id`/路径区分。
- [ ] 各层产物顶层键统一 `records`；ID 唯一性校验已跑（**ENT- 前缀豁免**）。

> **反例留档**：#28 目录复数 vs 索引槽位单数 → 7 层静默空回填｜#39 50 条规则只有 9 个唯一 ID 全撞 `ZG-R-501`｜#54 分配器只作用顶层，446/869 子节点无 ID。

## 四、G 族｜幂等与原子——「永不从空字典重建」

- [ ] 各层落盘走 `merge_layer()`（增量语义）；共享文件走 `merge_shared_json()`（增量合并，**永不从空字典重建**）。
- [ ] 写盘一律 `atomic_write_*()`（**临时文件 + rename**）。
- [ ] **单卷重跑（`--volumes NN`）后共享文件条数与全量一致**（不截断）。
- [ ] **全量重跑两次结果一致**（幂等）。
- [ ] **无一次性修复脚本落在正式生成器之外**（修复须并入 `build_*`）。

> **反例留档**：#12 `build_base --volumes` 把指纹库从 **1197 条抹成该卷条数**｜#14 并行子代理半写文件竞态。

## 五、P 族｜流程与语境——「判据写语义，不写形态」

- [ ] 判语域一律**锚定原文开头**（`SemanticGate`），**未用全串子串匹配**。
      > #47 `"留守司。" in scope_text` 致 `05-051`（卫指挥使司条，正文顺带提及"留守司"）漏填 3 条世官。
- [ ] 数值/单位解析**单点函数化**（`cn2int()`），无量纲前缀误读；**已先 grep 本书实际书写变体（约数后缀 / 量纲前缀 / 复合单位）再定剥离集**。
      > #48「一千四十四石」被读成 1+44 或 1444；#64「十三万二千馀石」静默返回 `None`，整棵总账树为空（**同函数第 2 次复发**）。
- [ ] 枚举校验用「**收集-报告-暂存**」不中断；`drift_ratio()` 已算，**>1.5 已处理**。
      > #27 事件类型 23→111 种、名录 **100% 库外**；#15 枚举校验报错终止致 **5 次中断**。
- [ ] 探查有**终止条件**，未过度探查（`ProbeTracker` 连续两次结论不变即收口）。
      > **#1 是历史最高频的坑。**
- [ ] **每次想加 `if` 特例时已追问**："这是『**地位排序**』问题，还是『**包含关系**』问题？"——包含关系**排序判据从原理上不适用**，须改显式父→子允许表，或不校验层级只校验「无环 + 节点唯一」。
      > #57 `LEVEL_RANK` 被当包含约束，v5 加 `{内府,监}`、v8 加 `{所,司}`、v12 加 `{院,中枢}` ——**同根因加三次特例**才发现判据本身错。
- [ ] 关系/层级类结果已**先验方向再验数量**（方向错时数量仍正常，计数发现不了）。
      > #52 古汉语「A…。B佐之」**B 才是佐者**，首跑配成「尚书佐侍郎」，方向转 180°。
- [ ] 台账类文件（`pending-review.md` / `registry.md`）的**升级动作与回填同一次完成**（无校验器兜底）。
      > #61 34 行状态停在「待评审」，实际 26 行早已入库——**表格行数 ≠ 待办数**。
