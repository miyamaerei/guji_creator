# 通用枚举基准库（Enum Library）

> 库版本：**v4**（2026-10-10 建 v1；2026-10-10 回写《蘧编》增量至 v2；2026-10-11 并入事件类型子库至 v3——原 event-type-library.md 废止，明细见 §1.3；2026-10-11 回写《客座赘语》全卷执行期增量至 v4——新增 GEO 段、文献改四部树、事件+4 顶层、名物/风俗/涉明/名录/实体扩充，见 §3 v4）。合并《新官轨范》《水东日记》《五杂俎》《蘧编》《客座赘语》五实例全部枚举（后续实例按 §2 接入）。
> 定位：所有枚举的**跨书基准值权威源**。每实例枚举 = 继承本库规范值快照 + 新书归纳增量（流程见 `enum-induction-guide.md`）；值多时按树组织（顶层大类封闭 → 子类 → 叶子，深度 ≤3）。
> 新枚举候选先进 `pending-review.md` 待评审区，评审通过才入本库（版本行+1）。

## 0. 机制

- **基准值继承**：新书直接用规范值（含使用说明），不再从零归纳；出现未匹配值 → pending 收集（不中断）→ 决议（新增/归并/暂存）→ registerVersion+1 → 回溯存量 → 更新本库。
- **别名映射**：各书历史值 → 规范值（回填通道），不新增规范值。
- **兜底**：每枚举保留兜底值（其他/unknown/未明）。
- **树状管理**：值 ≥15 或有天然层级时按树组织；父类计数 = 子类求和；实例按需继承子树。

### 1.1 实体类型 ENTITY_TYPES（20 值）
```

institution 机构（别名：org）
place 地名
era 年号朝代
work 文献书名（别名：book）
object 名物（别名：artifact 器物）——物部考据对象
animal 动物
plant 植物
food 饮食
doc 文书
system 制度
behavior 行为
punishment 刑罚
time 时间
quantity 数量
posthumous 谥号
star 星象（别名：astronomy 天象）——星宿/天象名实体：北斗、南斗、天枢等
```

来源：新官 11（person/official/org/place/doc/system/behavior/artifact/punishment/time/quantity）+ 水东 8（person/official/institution/place/era/posthumous/work/unknown）+ 五杂俎 10（person/place/book/office/era/object/animal/plant/food/unknown）合并归一；+《客座赘语》执行期新增 `star` `event`（v4）。
**新增说明**：`star` 因客座 unknown 344 条中星宿类 18 项（北斗/南斗/天枢等）无归属而立（笔记/类书言天象者多用）；`event` 立为事件专名（11 条：靖难/土木之难/宸濠之乱等），与 EVT 层的"事件类型"分工——本值是**实体名**，EVT 层是**事件分类**。同类未立值：疣痣类 4 项（疣子/紫痣等）证据过少，暂归 `unknown` 观察。

### 1.3 事件类型 EVENT_TYPES（27 顶层 + 43 子类型，树状；原 event-type-library.md 全文并入）

**机制**：顶层封闭 + 动态回填——新书出现未匹配值 → pending 收集（不报错终止）→ 决议（新增/归并/改名，新增必须有实例证据）→ registerVersion+1 → 回溯存量（dry-run 再 commit）。别名映射是"各书历史值 → 规范值"的回填通道，新书直接用规范值不再自造别名。**双层粒度**：新书继承顶层全集；子类型**按需继承**（史书/笔记/类书只继承顶层；官箴书/政书/流程体与行政过程同档时引入 §1.3.2）。每值带"语义+正反例"使用说明；兜底"其他"永远保留。
