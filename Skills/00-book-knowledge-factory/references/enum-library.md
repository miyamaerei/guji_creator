# 通用枚举基准库（Enum Library）

> **库版本：v4**（2026-10-11）｜变更历史、证据与待办 → `enum-changelog.md`
> **定位**：所有枚举的**跨书基准值权威源**。本文件只存"当前生效的规范值"，不存历史、不存理由。
> **用法**：实例化时按启用层拉取规范值快照（值 + 别名 + 使用说明一并带走）；新候选值先入 `pending-review.md`，评审通过才可入库——入库须**双写**（改本文件 + 追加 `enum-changelog.md` 版本条目）。归纳流程、新增/归并判定标准、树状设计见 `enum-induction-guide.md`。

## 0. 读法

- 格式：`规范值（别名：各书历史值）——使用说明`。**别名是回填通道**，不占规范值名额。
- 树状：`顶层 ─ 子类`（顶层封闭、子类开放登记，深度 ≤3）；实例按需继承子树。
- 兜底值（其他 / unknown / 未明）**永远存在且永远最后**；拒识优于乱识。
- 每段末尾一行「来源」只标出处与入库版本；证据与归并理由一律查 `enum-changelog.md`，不在本文件展开。

## 1. 枚举基准值总表（树状）

### 1.1 实体类型 ENTITY_TYPES（20 值）
```
person 人物

institution 机构（别名：org）
place 地名
era 年号朝代
work 文献书名（别名：book）
object 名物（别名：artifact）——物部考据对象
animal 动物
plant 植物
food 饮食
doc 文书
system 制度
behavior 行为
punishment 刑罚
time 时间
quantity 数量
posthumous 谥号
star 星象（别名：astronomy）——星宿/天象名实体：北斗、南斗、天枢等
event 事件名——事件专名实体：靖难、土木之难等；与 EVT 层分工：本值是"实体名"，EVT 层是"事件分类"
unknown 类型待定（兜底）
```
来源：新官 11 + 水东 8 + 五杂俎 10 合并归一；v4 新增 `star` `event`。未立值：疣痣类（证据不足，暂归 unknown 观察）。

### 1.2 规则类型 RULE_TYPES（7 值）+ 模态 RULE_MODALS（7 值）
```
禁止型(prohibit) / 义务型(obligation) / 允许型(allow) / 程序型(procedure)
/ 时限型(deadline) / 处罚型(penalty) / 优先级型(priority)
```
来源：新官 7+7（封闭全）。

### 1.3 事件类型 EVENT_TYPES（27 顶层 + 43 子类型，树状）

**机制**：顶层封闭 + 动态回填——未匹配值 → pending 收集（不报错终止）→ 决议（新增/归并/改名）→ registerVersion+1 → 回溯存量。**双层粒度**：新书一律继承顶层全集；子类型**按需继承**（史书/笔记/类书只取顶层；官箴书/政书/流程体与行政过程同档时才引入 §1.3.2）。

**分支 B · 名号称谓类（14 值；源自客座赘语 NAM 688 条）**
```
人物 / 官员 / 文人 / 僧侣 / 皇族 / 称号 / 别号 / 斋号 / 谥号 / 尊称
/ 绰号 / 官职别称 / 物名异称 / 群体称谓
```

使用说明：人物=个体通称；官员/文人/僧侣/皇族=身份类别；称号/别号/斋号/谥号/尊称/绰号=名号类型；官职别称=职官的俗称别称（如"大司空"）；物名异称=器物的俗名异名；群体称谓=某一群人的合称。

## 2. 实例接入

1. **取快照**：按本书启用层，从本库拉取对应枚举的规范值 + 别名 + 使用说明 + 树结构，固化进 `_kg_enums.py` / `references/schemas.md`，并标注"基准库 vX 快照"。事件层按 §1.3 粒度规则决定只取顶层或加子类型层。
2. **收增量**：执行期未匹配值 → pending 收集（不中断）→ 决议 → registerVersion+1 → 回溯存量。**候选新值先入 `pending-review.md`，评审通过才入本库**（流程见 `enum-induction-guide.md`）。
3. **回写库**：入库必须双写——改本文件对应段（含使用说明）+ 在 `enum-changelog.md` 追加版本条目；归并只更新别名映射，不新增规范值。
