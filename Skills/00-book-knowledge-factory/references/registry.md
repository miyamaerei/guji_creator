- **状态**取值：`探查中` / `反思中` / `实例化中` / `已交付（待执行）` / `执行中` / `全量执行完成` / `已归档`。

- **案例反馈**列指向工厂内的 `references/case-feedback-<book-slug>.md`；实例的反思**过程**记录存这里，实例本身只固化结论。
- 表中信息与实例实际不一致时，以实例 SKILL.md 为准并回改本表。
- 新实例交付时同时在本表登记；实例退役/归档只改状态不删行。
