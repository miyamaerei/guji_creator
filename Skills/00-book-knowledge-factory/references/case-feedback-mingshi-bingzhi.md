## 1. 本实例的三条「元教训」

1. **同一部《明史》的第三个「骨架」，必须先问「对象是什么」**。职官志对象=机构（zgz 型 ORG 树）、食货志对象=制度（shz 型 REG+QUAN）、**兵志对象=「卫所编成树 + 军政制度」双骨架**（bz 型）。这是坑 #0.1「层模板套用」的第 3 次复发——若套 shz 型的 QUAN/INST/FISC，卫所编成的**树状归属**（府→都司→卫→所）将无处安放。
2. **树状编成 ≠ 制度沿革 ≠ 名录**。卫列行（`杭州前卫杭州右卫台州卫…`）是**编制陈述**不是名录谱牒（不建 NAM，坑 #36 判别标准）；但它们的组织结构是**树**，不是 L4 扁平的 ORG 数组——需要**专门的树层 C17**。
3. **无分隔长行切段是「规则引擎无法独立完成」的典型**。纯正则按 SKILL.md §6.3 初版实测覆盖率仅 8.1%；必须改「括注锚点 + 词典贪心 + 未解段 AI 复核」，且**未解段严禁硬猜边界**（坑 #54/#55 本实例独立复发为卫列场景）。

## 2. 可跨书复用潜力

### 2.1 层方案与结构（可直接复用的设计）

| # | 项 | 说明 |
|---|---|---|
| 1 | **bz 型方案组合** | 正史典志体·兵志门 9 层：L0/L1/L2/**REG**/**C17 卫所树**/C14/C9/**OBJ（薄层）**/**L4 四维（EVO·QUAN·WEI·REW）** + 索引 |
| 2 | **C17 卫所树（双清单分树）** | 同一部书的**两版编成**（旧定/后定）各建一棵树（`list_ver`），`name_norm` 去方位字做对照；适用于任何「同一对象有两版清单」的古籍（会典、实录、兵制、赋役） |
| 3 | **卫所标记文法三层解析**（`◎府`/`○在京`/`△都司` 标记 + 无标记卫列行） | 标记**不保证必现**（中军都督府无 ◎、在京无 ○、辽东都司无 △）——语义判定锚定**行首/上下文**，不依赖单个标记（坑 #47 位置消歧） |
| 4 | **括注锚点 + 词典贪心切段** | 无分隔卫列长行：先按 `X卫(注)Y卫` 在括号处断开（括注前词必然完整），再词典最长匹配；未解段整段标 `ai_review=required` **不硬猜边界** |
| 5 | **WEI_NAME_INDEX 渐进式同名词典** | 括注锚点预扫收词（冷启动 37.4%→63.6%）+ AI 每复核一批回填一批（→完备词典 99.5%+）；**词典不一步到位，覆盖率如实计算不虚报** |
| 6 | **括注 ≠ 卫名** | `(调北京)`/`(革)`/`(旧《会典》作兀里)` 是沿革注，剥离后进 `notes[]`/C14；**括注同时是硬边界**（括注后必为新卫名开头） |
| 7 | **`已上`/数量行是区块级信息** | `已上俱改为亲军`/`卫三百八十四` 只挂区块节点，**不复制到每个卫**（防数据虚增 + 漂移） |
| 8 | **双树对照三态视图** | 逐都司输出「旧有/新有/两树皆有」；**凡两树同卫名但括注不同，以 `src_loc` 保留双证据，不合并覆盖** |
| 9 | **REG 兵志 7 token** | `geo_ref / num_value / num_unit / num_semantic / src_loc / cross_ref / mil_class`——制度层的兵政定制（契约标 5 字段，按实测取 7 值） |
| 10 | **L4 兵志四维** | EVO 沿革 / QUAN 数额（复用坑 #64 教训：约数后缀全串剔除）/ WEI 卫所编制 / REW 赏功等级——其中 WEI 与 C17 树节点**共用 ID 前缀**（编制维引用树节点，设计如此） |

### 2.2 分层与抽取纪律（判断口径）

| # | 项 | 说明 |
|---|---|---|
| 11 | **奏议引语与制度站队区分** | C9 只收原文带说话人且 >40 字的声明句（41 处言）；「从之/报可/帝是其言」是决策结果进 C14/TME，不进 C9 |
| 12 | **卫列行归 C17 不归 NAM** | 判据：含人名四元组者建 NAM，仅含官职员额/卫所名者归 C17（坑 #36 判别标准同源） |
| 13 | **含句读的行是说明段** | 卫列行是**无标点纯名串**；含 `，。；：` 的行是说明段（如亲军上二十二卫说明）归 REG/总述；**但括注内句读要先剥离再判**（`卫(后改名武定，属后府)` 是卫列非说明段） |
| 14 | **南京/羁縻卫所分三棵子树** | 后定编成含北京五府 / 南京亲军+五府属 / 羁縻三子树，**不得混挂** |

### 2.3 坑（需防范的错误模式）

| # | 坑 | 出处 |
|---|---|---|
| 17 | **套用兄弟实例的四维而不重问对象** | 本书若套 shz 四维，卫所树的层级归属无处安放（#0.1 第 3 次复发） |
| 18 | **纯正则切无分隔长行** | 按 SKILL.md §6.3 初版实测覆盖率仅 **8.1%**；须改括注锚点 + 词典贪心 + 待复核段（承 #54/#55） |
| 19 | **段尾多词尾不做计数** | `水军左卫骁骑右卫(调北京)` 被当单一卫名；须段内词尾计数，`>1` 强制词典分解或整段 pending |
| 20 | **括注挂段首叶** | `通州卫(已上俱改为亲军)` 的注挂到段首燕山左卫；括注紧贴词尾，必须挂**段尾最后一片**叶 |
| 21 | **`已上` 行级先于括注剥离** | `(后为隆庆卫已上俱属后府)` 被误截断留左括号；先拆括注再检已上，已上只作用无括注尾部段 |
| 22 | **卫列行句读检查不剥括注** | `青州左护卫(后改名武定，属后府)` 的括注内逗号使整行误判说明段；先剥离括注再看行级句读 |
| 23 | **WEI- 前缀跨层被 ID 校验误杀** | C17 卫所树节点与 L4-WEI 编制维共用 `WEI-` 前缀（设计如此）；`assert_unique_ids` 须豁免 `("ENT-","WEI-")` 对 |
| 24 | **终账行/张本行进树** | L121「后定天下都司卫所…」总账段含句读、L51/224 张本行是总起——整段入 C14/QUAN，**不入树** |

## 5. 对工厂的回馈

1. **新增方案组合「bz 型」**（正史典志体·兵志门 9 层），与 zgz/shz 型并列；三者**同源异形**关系已在 layer-library v16「同源异形警示」上再续第 3 例（对象=卫所编成树 + 军政制度）。
2. **C17 卫所树候选为自定义层**：其「双清单分树 + name_norm 对照」抽象与书目无关——凡**同一对象有两版清单**的古籍（兵志、会典、实录、赋役、钞关）皆可复用。抽象层级高于「卫所」本身，可称**双版本对照树**。
3. **无分隔长行切段三件套（括注锚点/词典贪心/待复核段）** 建议沉淀为**通用长行切段策略**入 methodology 或骨架工具——同类问题（职官志员额行、食货志税额行）此前依赖逐实例正则，本次证明「锚点 + 渐进词典 + 显式待复核」是收敛路径。
4. **块标题兼容性**：块标题判定必须覆盖「无标记裸行」（`上十二卫`/`在外`），不能只信 `◎/○/△` 标记——与食货志「○ 不保证必现」同源（#33/#47 同类）。
5. **ID 跨层豁免须显式登记**：`assert_unique_ids` 的豁免对（`ENT-`,`WEI-`）是设计事实而非缺陷——建议骨架注释与校验器文档同步说明「跨层共享前缀的合法场景」。
