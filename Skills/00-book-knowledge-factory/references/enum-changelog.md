# 枚举库变更记录（Enum Changelog）

> 本文件是 `enum-library.md` 的**历史账本**：只记录"为什么改、改了什么、证据是什么"。
> `enum-library.md` 只存**当前生效的规范值**，不存历史——每次入库必须同时在本文件追加一个版本条目。
>
> **约定**
> 1. **只增不改**：已发布的版本条目不得编辑或删除；写错了就在新版本里更正。
> 2. **新版本追加到文件末尾**，并同步更新顶部「版本索引」表。
> 3. **入库动作是双写**：改 `enum-library.md` 规范值 + 在本文件追加版本条目 + 在 `enum-library.md` 顶部版本行 +1。三者缺一即视为野分支（见 `pitfalls.md` #27）。
> 4. 证据写数量与样例即可，不贴全文；原文可回溯到实例的 `_deliver/` 或 `reports/`。
