# 《五杂俎》TRL 翻译风格规范（余光中风格，已固化）

> 本规范为古今翻译层（TRL）的**强制风格基准**。由用户指定（"固化风格基准，并且所有翻译都固化成这样"），2026-10-10 依据余光中翻译观提炼固化，与《水东日记》TRL 同基准。**执行 TRL 时逐条翻译一律按本规范**；style 字段仍填直译/意译/注释性翻译（译文风格判定），note 中标注"余光中风格基准"；如有条目需偏离（如引书原文、诏敕原文需保留格式），在 note 中说明理由。

## 0. 风格依据（余光中翻译观要点，外部研究摘要）

1. **"要译原意，不要译原文"**——只顾表面原文、不顾背后原意，就会流于直译、硬译、死译。
2. **翻译如婚姻，两相妥协**——既不许洋腔洋调的中文，也不许油腔滑调的中文。
3. **"白以为常，文以应变"**——以白话为骨干，文言作调剂；白话不足，济之以文言。
4. **反对恶性西化/翻译体**——公式化连接词（见 when 就"当"）危害中文节奏；主张"善性西化"。
5. **中文是并联句法**——长句由几个身份相当的短句串连而成，前呼后应。
6. **精简防冗余**——删"多余的字句"，不用"人们""……之一""进行"等冗余西化词。
7. **善用四字格**——适度使用四字词语/成语，彰显中文之美，自然不造作。
8. **"译无全功"**——翻译是"逼近"的艺术，允许在忠实与可读间妥协。

## 1. 七条翻译规范（可操作）

### 1.1 译原意，不译原字
- **做法**：先整体理解条目原意（议论/考据/轶事/风俗），再按现代汉语表达原意；句序、语序可调整，不以逐字对译为纲。
- **反例**（死译）：「夫理者，天之主宰也」→"那理这东西，是天的掌管者"（"那……东西""掌管者"直译腔）。
- **正例**：「理，就是天的主宰」。

### 1.2 主从改并联（长句拆短句）
- **做法**：古文长句（多重修饰/插入/考据罗列）拆为几个身份相当的短句串连，顺应中文并联句法，不用"……的……的……"叠床架屋。
- **正例**：「天，积气尔，此亘古不易之论也」→「天是积气，这是亘古不变之论」。
- **正例**（考据罗列）：「按《汉书》曰……又云……二说互异」→「按《汉书》说……又说……两种说法互有不同」。

### 1.3 白以为常，文以应变
- **做法**：以现代白话为骨干；人名/地名/书名/职官/年号等术语保留原词（必要时括注）；引用原书关键句、诗句、奏对可保留文言原貌并加引号。
- **示例**：「今闽人方音尚以雨为辅」→「如今闽人方言仍把'雨'读作'辅'音」（音证保留）或「今闽人方言仍以'雨'为'辅'」。
- **示例**（书名）：《礼统》《汉书》《酉阳杂俎》保留书名号原样。

### 1.4 精简防冗余
- **做法**：删除"多余的字句"——文言虚词（之乎者也矣焉）按现代习惯省略；不添加现代翻译腔的冗余连接词（"被……所""……之一""进行""加以"等）。
- **示例**：「客星犯帝座，此史官文饰之词耳」→「客星犯帝座，不过是史官文饰之词」（不加"这是属于……的"）。

### 1.5 善用四字格
- **做法**：语感允许处使用四字词语/成语，彰显中文之美；不生造、不堆砌。
- **示例**：「朝中正人为之一空」→「朝中正人为之一空」（保留四字）；「余意其必有异」→「我料想其中必有蹊跷」。

### 1.6 忌翻译体公式
- **做法**：不套用公式化句式——如"当……时""在……中""关于……"非必要不用；不用"其……之……"的欧化同位结构。
- **示例**：「万历丁丑十月，异星见西南方」→「万历丁丑年十月，西南方出现异星」（不译"在西南方"）。

### 1.7 专名保留 + 括注（忠实与可读的妥协）
- **做法**：人名/职官/机构/地名/年号/书名保留原词；首次出现可括注今释或别名；职官名遵循明史职官术语（"内阁"不译"宰相办公室"，"太守"可括注"知府"）；书名保留《》并首次出现可括注今通行本名。
- **示例**：「近时闽中林太守春泽公」→「近时闽中林太守林春泽公」或「近时闽中太守林春泽」；「逆瑾」→「逆瑾（刘瑾）」。

## 2. 应用示例（条目 13-001 知命论，按余光中风格）

**原文**：圣人之贵知命，谓安于命，不趋利避害也；今人之欲知命，则求趋利避害也，是不谓之知命，谓之逆天。

**译文（直译·余光中风格基准）**：
圣人看重"知命"，是说安于命运，不趋利避害；今人想"知命"，却是为了趋利避害——这不能叫知命，该叫逆天。

**对照七条**：1.1 原意优先（"贵"译"看重"不译"尊贵"）；1.2 分号前后两短句并联；1.3 "知命"保留原词加引号；1.4 省"也""矣"类虚词；1.5 "趋利避害""安于命运"四字格；1.6 无"当……时"公式；1.7 "圣人/今人"直译，专名无特殊。
