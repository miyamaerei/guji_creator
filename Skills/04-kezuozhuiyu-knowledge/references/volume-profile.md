## 2. 各模式处理指引（本书定制）

| 模式 | 处理重点 | 覆盖缺口自查 |
|---|---|---|
| 制度优先 | EVT（朝政/经济/科举）/ APPT / MING（制度） | 抽查 NAM 是否有隐性题名录（卷三谥、卷十官职群） |
| 人物优先 | ENT（person 归一 aliases）/ REL / APPT / MING（人物） | 同人异称是否全部收 surfaces；同名异人入 V2 待核 |
| 名物优先 | OBJ / ENT（object/plant/food）/ CUS（物产习俗） | attributes 无文本证据不编造；与 CUS 物产习俗分界 |
| 风土优先 | GEO / CUS / CIT（志乘考源） | 地理方位、沿革、考证来源（evidence）是否齐 |
| 名录优先 | NAM / ENT（person 批量） | entries 数组化完整；逐一 office/hometown 有无 |
| 轶事优先 | EVT（轶事）/ REL / TRL | 事件五元组 when/where 未明显式写"未明" |
| 文事优先 | EVT（文事）/ LIT / CIT | 整篇收录与引用征引分界（LIT vs CIT） |
| 均衡全层 | 全层 | 卷完成对照表内类型逐层核对 |

## 4. 校准流程

① 逐卷抽样（首段+尾段 500 字）→ 关键词密度（题名/录/碑/记/奏/书/诗/诏/谱/图等）→ AI 逐卷判定；② 固化标注表（修正本文件）；③ 执行任一卷前查模式，按其处理重点分配抽取优先级；④ 卷完成后对照主导/次要类型检查覆盖缺口；⑤ 与卷内实际不符 → 以实际为准回填修正（registerVersion+1）。
