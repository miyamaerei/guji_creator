## 关键教训（更新）
1. **修源文件，不修合并层**——这个错误犯了两次，必须形成肌肉记忆。任何对 `_layers/` 的修改，都必须同时回写 `_data/volNN/` 源文件。
2. **旧单文件必须拆分入 volNN/**：`_merge_all.py` 只扫 `_data/vol*/` 目录，任何不在这个目录下的 JSON 数据都是隐形的。
3. **补丁脚本必须改源文件**：写补丁脚本时，目标应该是 `_data/volNN/*.json`，不是 `_layers/geo/all.json`。
4. **重建流程**：清空 _layers → 建空 all.json → 跑 _merge_all.py。永远不要用 build_merge.py（会重置 registry）。
5. **县名提取数据要存 git**：`nanzhili_extract.json`/`shanxi_extract.json` 存在 `_work/` 下，即使源文件丢了也能从 git 恢复。
