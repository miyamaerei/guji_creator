# 《大明一统志》知识工程交付包

## 目录结构

```
deliver/
├── 00_README.md              # 本文件
├── 01_报告/
│   └── 交付报告.md           # 项目总结 + 统计 + 后续待办
├── 02_数据/
│   ├── geo_tree.json         # GEO 地理树（2006 节点，带 children + 各层计数）
│   ├── full_kb.json          # 7 层全量合并知识包
│   └── summary.json          # 统计摘要
└── 03_可视化/
    ├── vis_geo_tree.html     # GEO 树浏览器（可展开折叠）
    ├── vis_region_bar.html   # 各布政司 GEO 节点数柱状图
    └── vis_layer_pie.html    # 7 层数据分布饼图
```

## 快速开始

1. 打开 `03_可视化/` 下任意 html 文件即可查看（需联网加载 echarts CDN）
2. 数据文件在 `02_数据/`，JSON 格式可直接被程序读取
3. 详细统计和后续规划见 `01_报告/交付报告.md`

## 核心数据

- 总条目：49,429 条（7 层）
- GEO 节点：2,006 个
- 覆盖：16 个布政司/都司 + 56 个外夷国
- 验证状态：ERR=0 全量通过
