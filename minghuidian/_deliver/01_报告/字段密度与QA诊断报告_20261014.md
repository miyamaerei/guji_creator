## 二、树的二级展开诊断（本轮核心）

### 2.1 问题：州→县展开率为 0

初次体检发现：

```
州/县   有子  0/1369 = 0.0%      ← 全部 251 个州都没有属县
府      有子  144/154 = 93.5%
```

即「府→县」是平的：**1118 个县全部直接挂在府下**，属州（如泰安州、德州）成了光杆节点。

### 2.2 根因：图志的三级结构被拍平

明会典·图志（卷17–18）的真实格式是**嵌套**的：

```
济南府领州四县二十六
厯城县 章丘县 … 陵县          ← 15 个「府直辖县」
泰安州                        ← 属州游标开始
新泰县 莱芜县                 ← 2 县归泰安州
德州
德平县 平原县 武定州           ← 德平县/平原县归德州；武定州另起
阳信县 海丰县 乐陵县 商河县    ← 4 县归武定州
滨州
利津县 霑化县 蒲台县兖州府领…  ← 3 县归滨州；随后是兖州府头
```

原解析器**未跟踪「属州游标」**，把遇见的每个 `X州` 与 `X县` 一律挂到当前府，导致州→县关系丢失。

### 2.3 修复：引入属州游标 + 左至右最长匹配切分

重写 `_p2d_build_geo.py` 的图志解析，关键四点：

1. **属州游标**：遇 `X州` 后，其后所有 `X县` 归该州，直至下一州/下一府头；
2. **属州配额**：以 `X府领州a县b` 的 `a` 为配额，超出者判为**直隶州**（隶布政司）——据此自动识别出山西5、四川6、广西8、南直隶4 等直隶州；
3. **左至右最长匹配切分**：替代原正则，杜绝 `邦水长官司独山州`、`邠州淳化县`、`陵县泰安州` 之类跨名误切；
4. **PUA 字形还原**：`隶`=U+E5AB 等 180 个私用区字符归一（此前「北直隶/南直隶」因 `隶` 是 PUA 而完全识别不出）。

### 2.4 修复效果

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 州有属县比例 | **0.0%** | **66.9%** (162/242) |
| 府级县数吻合 | — | **99.0%**（112/122 府完全相等） |
| 省府数吻合 | 15/15 | **15/15** |
| 省州数吻合 | 9/15 | **15/15** |
| 直隶州识别 | 6 个（且为省界文字误抽） | 正确（山西5/四川6/广西8…） |
| 树深度 | 0/1/2 层 | **0/1/2/3 层**（省→府→州→县） |
| 节点 | 2583 | 2595，悬空 0 |

**济南府验证**：直辖 15 县 + 泰安州2 + 德州2 + 武定州4 + 滨州3 = **26**，与原文「领州四县二十六」完全一致。
