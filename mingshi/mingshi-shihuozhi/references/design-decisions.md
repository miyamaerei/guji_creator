## 4. 四个待裁决项的取证结论

### 4.1 OPN 判据（用户问「要不要建」）

**证据**：`言：` 98 处（长段引述臣工奏议）；`疏：` 0；《》 仅 2 处。
**判定**：**值得建**——奏议是本书批评/建议的载体，与 REG 的 `abuses[].opn_ids[]` 直连。
**判据写死**：`len(quote) >= 40` **且** 命中`OPN_CLAIM_MARKERS` 18 词之一。

### 4.2 马政（用户问「马政总账」）

**取证**：马政 4 / 茶马司 13 / 马市 10 / 草场 8 / 马价 3 / 折银 41；**太仆寺 0 / 苑马寺 0 / 种马 0 / 儿马 0 / 骒马 0 / 民牧 0 / 官牧 0 / 俵马 0 / 牧监 0 / 群长 0 / 孳生 0**
**判定**：**原文无独立马政篇**，马政仅附茶法（食货四）。「马政总账」不存在。
**用户裁定**：**不建**。
**可给的替代**：茶马司易马数据（茶 172 / 马 146）落在 REG-茶法 + QUAN。

### 4.3 县级税额（用户问「一个县交多少税」）

**取证**：`天下户口有户口之银，人丁有人丁之银，田土有田土之银，有司徵收，总曰银额。`（L56 银额公式）；一条鞭法 `皆计亩徵银`；逋欠 `一县有至十万者`。
**判定**：**原文无「一县交多少」的统一定额**，只有规则与公式。
**用户裁定**：**不建查表**。
**替代**：可作「算式器」——按 `亩税率 + 丁银 + 银额公式` 推算，但不落静态表。

### 4.4 REG 与 L4-INST 的分工（防第四次刻画）

## 7. 实现阶段的三个关键设计决定

### 7.1 切分不走 ○ 标记

卷五十三子目行**无 ○ 标记**（`户口田制(屯田庄田)` L5），故判据必须用「被正文包围的无句号短行」。
与职官志坑 #33 **同源异形**——同是「无条级标记文本的行=条口径」，但本书**部分条有标记**，更具迷惑性。

### 7.2 约数后缀必须优先处理

本书数额**绝大多数带 `馀 / 有奇`**，且**可夹在数字中间**（`四百三十馀万束`）。
不处理则 `cn2int` 静默返回 `None` → **整棵总账树为空且不报错**（A 族静默失败）。
→ 已登记为工厂坑 #64，并修进骨架 `cn2int`。

### 7.3 `side="未分"` 是合法值

13 镇中 **甘肃(L278)、固原(L279) 无主兵/客兵分列**。
解析器须容许 `QUAN_SIDES` 的第三个值 `未分`，不得因缺 `主兵`/`客兵` 报错。
