### 0.2 内容形态：**时序沿革叙事体**（不是三段体）

《职官志》是「编制行 / 职掌行 / 沿革行」三段体，**本书不是**。本书是**按时间推进的叙事**：

```
初置某制 → 其间增损 → 弊生 → 谋议 → 改革 → 结果
```

**这直接决定了：本书的骨架是「制度（REG）」而非「机构（ORG）」。**

### 0.3 标记体系（三层）

```
◆【第五十三~五十八章·卷五十三~五十八】食货一~食货六   ← 卷标 6 行（L1/30/73/108/182/233）
◎食货一~食货六                                      ← 卷内标题 6 行（L3/32/75/110/184/235）
○赋役 / ○漕运仓库 / ○盐法茶法 / ○钱钞坑冶…商税市舶马市 / ○上供采造…俸饷会计  ← 仅 5 行
```

**关键陷阱**：卷五十三**没有 `○` 标记**，其子目为无标记短行 L5 `户口田制(屯田庄田)`。

### 0.4 切分口径

**判据**：**被正文包围的无句号短行** = 条（与《职官志》坑 #33 同源异形）。

**两个失败判据（留档，勿重犯）**：
1. ❌ 按 `◎` 后遍历、遇 `。` 即停 → 卷序论含句号，会提前中断；
2. ❌ 从首个含 `。` 行向前回溯 → 首个即 index 0，无处可回溯。

### 0.5 引导式反思记录

**用户方向**：用户 m05345 主动给出六项具体需求（户口户籍 / 土地制度 / OPN 论说层 / 制度属性 / 国家总账树形图 + 一把捞组装器 / 征收物四元组 + 运送途径），方向明确，无需工厂再引导。

**层库参考**：对照 `layer-library.md` 现有方案组合（zgz 型 / fqh 型 / lgs·xzl 型 / ysz 型 / ppy 型 / minghuidian 型），本书**无一完全匹配**——同属《明史》典志体的 zgz 型以**机构**为对象，本书以**制度**为对象。故**新建 shz 型**。

**确认结论**：8 层全建 + C16 总账树，用户 m05362 已逐项拍板（详见 `references/design-decisions.md`）。

### 4.2 已知陷阱

- **`object` 的别名是 `artifact`**，`work` 的别名是 `book`——**不要写 `book`/`other`**（职官志时曾因非法类型报 ERR）。

## 8. L4 食货四维（定制，替代 ORG/RANK/LINE/EVO）

### 8.1 四维定义

| 维 | 前缀 | 对象 | 说明 |
|---|---|---|---|
| **QUAN** 数额定额 | `QUAN-` | 数量 | 物品 + 本色/折色 + 数量 + 单位 + 归属 |
| **INST** 制度类型 | `INST-` | 类型 | 制度标签，反指 REG |
| **EVO** 沿革阶段 | `EVO-` | 阶段 | 初置/定制定型/增改/裁革/复设/变法/弊坏/复原 |
| **FISC** 财政流转 | `FISC-` | 环节 | 徵收/起运/存留/解京/内库/边镇/支放/加派/蠲免/折纳/转运 |

### 8.2 QUAN 的核心：四元组

用户 m05345 要求：「征收物之类的，需要是某某种，实物/银，多少数量，多少单位」

```python
{"item": "米", "form": "本色", "amount": 4000000, "unit": "石"}
```

**本体/折色二分法是核心形态开关**（全书 折色 36 / 本色 37）：
> 於是谓米麦为本色，而诸折纳税粮者，谓之折色。

**折纳定例（L37 区，可直接建表）**：
> 钞一锭，折米一石；金一两，十石；银一两，二石；绢一疋，石有二斗；棉布一疋，一石；苎布一疋，七斗；棉花一斤，二斗。

### 8.3 三个实现纪律

1. **约数后缀必须优先处理**（坑 #64）：`十三万二千馀石` / `四百三十馀万束` / `万两有奇`。
2. **`side="未分"` 是合法值**：13 镇中甘肃(L278)、固原(L279) 无主兵/客兵分列，不得因此报错。
3. **单位必带量纲**：`QUAN_UNITS` 映射到 容量/重量/货币/织物/土地/计数 六类。实测分布：
   `石 202 / 两 90 / 分 77 / 贯 57 / 斤 53 / 钱 47 / 文 43 / 匹 36 / 顷 15 / 亩 10 / 疋 8 / 锭 7`

## 16. 执行注意（易错点清单）

1. **切分**：卷五十三无 `○`，须用「被正文包围的无句号短行」判据。
2. **`cn2int`**：`馀 / 有奇` 必须剥离，且可夹在数字中间（坑 #64）。
3. **枚举**：`object` 别名 `artifact`、`work` 别名 `book`，**无 `book`/`other` 类型值**。
4. **纪年**：后续原文裸写「四年」「五年」，实体 text 须去朝代前缀。
5. **`LAYER_SPECS` 是 list of 3-tuples**，不是 dict（坑 #63）——同名三处（`_common.py` / `_kg_enums.py` / `build_kg_join.py`）必须一致。
6. **`side="未分"`**：甘肃 / 固原两镇无主客兵分列，合法。
7. **复合句**：印信/总账类长句含多组「项+数额」，须按标记切段（坑 #55）。
8. **多卷参数**：PowerShell 下 `--volumes 01,02,03` 会被拆参致 0 条，**须逐卷跑或用缺省全量**。
9. **中文校验**：PowerShell 控制台中文乱码是 codepage 问题（文件本身 UTF-8）；校验中文内容须写临时 `.py` 文件再跑。
10. **每次 pwsh 调用**须设 `$env:PYTHONIOENCODING="utf-8"`；heredoc 在 pwsh 下不可用。
11. **源数据文件**：多段内容**必须一次 Write 写全**，不可多次追加（坑 #12 变体）。
12. **新增子节点必须同步补 LINE/边**（若建树）——本实例 C16 树同理，改动后须重跑 `_ledger_builder.py`。
