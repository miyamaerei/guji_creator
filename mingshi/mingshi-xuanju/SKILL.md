## 2. 工程侧护栏（打包器骨架，Phase ③ 必接）

> 依据：工厂 `references/error-taxonomy.md`（A/B/G/P 四族）。装置见工厂 `assets/skeletons/packer_skeleton.py`；本实例 `scripts/_common.py` 已复制并填 `LAYER_SPECS`（11 层三元组同源）。**改动任何护栏函数后必须重跑 `assets/skeletons/self_test.py`**（本实例已验证 `PASS 36 / FAIL 0`）。

1. **B 族命名契约**：目录名 / 文件名前缀 / 索引槽位名 / schema 键名四处同源，只用 `LAYER_SPECS` 声明一次；子节点 ID 走 `assign_child_ids()`（派生 `<父ID>#<序号>`，保留已有 id，防双遍历器互覆——坑 #54/#39）。
2. **P 族数值解析（本实例高危）**：`cn2int()` 必须处理**量纲前缀**（一千四十四=1044）、**约数标记全串剔除**（`四百三十馀万束`=4,300,000）、**裸万**（`万`=10000）。返回 `None` 一律当**错误**处理，不得静默当 0（坑 #48/#64）。
3. **P 族语域锚定**：判章节/条目语义一律 `SemanticGate` 锚定开头（`startswith`），防正文字形词污染（坑 #47）；科举/学校/铨选语域判定锚定原文前 60 字。
4. **A 族填充率体检**：每个扩展字段（选举 token / QUAN 各子字段 / L3 场次/考官 / NAM 四元组）登记进 `FieldCoverage`；**填充率 0 直接判失败**，排查顺序：① 回填器是否真被 build 调用（坑 #56）→ ② 解析覆盖面是否漏组（复合句/超长行——坑 #55）→ ③ 最后才接受「原文确无」；占位「未明」是合法值，不算填充（坑 #45）。
5. **G 族幂等/原子**：写盘一律 `atomic_write_*()`；分层落盘 `merge_layer()` 增量语义；共享文件 `merge_shared_json()` 永不从空字典重建。
6. **问句验收护栏**：交付前必须跑「目标查询问句逐问实测」（§0.1 十问），输出「能答/半答/答不了」三态表——**ERR=0 只证明层内自洽，不证明能回答问题**（坑 #49/#50）。答不了须分类「原文确无」或「结构缺陷」。

3. **条目切分口径**：`◆【第N章-卷N】` 卷标为一级边界；`◎选举N` 为卷内大标题；**卷内无 `○` 子目标记**，子目（学校/科目/荐举/铨选）是叙述性嵌入（"学校有二：曰国学…"），需按语义切段，不按行号。→ `_extract/<vol>.txt`（预计按子目切成约 40–60 段，需试点定稿）。
4. **指纹库** `_item_registry.json`：key=`NN-NNN`，value=original/norm；norm 归一规则：异体字、缺字、标点统一。
5. **业务 ID 由打包器自动分配**：AI 源数据只写卷内顺序槽位，不手写业务 ID；打包器按全局序号 `enumerate(records, 1)` + 段位分配（容量 500）——坑 #39；`ENTS` 层 ID 为实体主键，**豁免撞号校验**（同一实体多次出现共用 ID）。
6. **写盘与并行纪律**：写文件一律「临时文件 + rename 落盘」；共享汇总文件增量合并语义（`--volumes` 只重算请求卷）——坑 #12/#14；验证脚本写文件输出，不依赖 stdout——坑 #6。

## 6. REG 制度层（本书骨架）

### 6.1 完整 schema（13 属性 + 选举追加 token）

继承工厂 REG 基准 13 属性（name / category / evolution+tme_ids / agencies / targets / levied_items / rates / scope+regions / documents / agents / purposes / abuses / source+source_item_id+evidence），**追加选举 token**：

| token | 字段 | 说明 |
|---|---|---|
| 选举类别 | `selection_type` | 科目 / 贡举 / 荐举 / 铨选（四途） |
| 学校类别 | `school_type` | 国学 / 府州县学 / 社学 / 武学 / 宗学 |
| 考试层级 | `exam_tier` | 童试 / 科考 / 乡试 / 会试 / 殿试 |
| 科场环节 | `exam_stage` | 应试资格 / 考场规条 / 三场内容 / 放榜 |

## 19. 执行注意（本书特有坑，先读再抽）

1. **卷内无子目标记**：`◆/◎` 每卷仅 1 个，子目（学校/科目/荐举/铨选）是叙述嵌入，须语义切段，不得按行号硬切（坑 #24 变体）。
2. **QUAN region 维度**：解额/会额按省分列，缺失 region 则"各省差异"（问句 2）答不了；约数标记全串剔除（坑 #64）。
3. **L3 考官/场次**：卷46 三场内容（四书义/经义/论/判/诏诰表/策）与考官名（11 处）必须进 `examiners[]`/`sessions[]`，否则流程层空壳。
4. **C9 抽验**："言"多数为子串（名言/姓名），只抽真实主张句（≥40 字 + 主张标记）；非主张不抽（坑 #34）。
5. **NAM vs L1 分工**：人名四元组进 NAM，归一实体进 L1；同名消歧靠 alias_index + provenance（宁建勿并）。
6. **FRD/L5 互补**：FRD 记弊案手法（冒籍/倩代/关节），L5 记完整叙事始末；二者不重复但须 `related_*` 互指。
7. **跨库联动**：及第授官/科道考选以 REG.cross_kb 指职官志，不单列 APPT 层；科费/廪给 cross_ref 食货志。
