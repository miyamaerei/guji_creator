## 2. 关键结构特征（影响切段与层设计）

- **卷内无 `○` 子目标记**：`◆`/`◎` 每卷仅 1 个（卷级 + 卷内大标题），子目（学校/科目/荐举/铨选）是**叙述性嵌入**（"学校有二：曰国学，曰府州县学""科举必由学校"）。→ **必须语义切段，不按行号硬切**。
- **行极长**：58 行承载 76KB，行均约 1300 字，密度极高。单条 AI 判定需整段语义理解，不能按行机械切。
- **四途为骨架**：学校/科目/荐举/铨选四途对应四套制度，天然形成 REG 制度层的主干。

## 4. 锁层方案（xjz 完整型，11 层 + L5 事件层）

详见 `../SKILL.md` §0.1。要点：
- **骨架** = REG 制度（13 属性 + 选举 token）
- **强结构** = L3 流程（科举三级乡/会/殿，含场次/考官）
- **数量** = L4-QUAN（解额/会额/监生额，加 `region` 维度按省分列）
- **沿革** = C14 TME + L4-EVO
- **名录** = NAM（一甲/考官/题名）
- **防弊** = FRD + L5 事件（科场弊案始末）
- **论说** = C9（科举利弊/掣签之议，须抽验真实主张句）
- **名物** = OBJ 薄层（八股/贡院/武科器械）
- **联动** = REG.cross_kb 指职官志、cross_ref 指食货志(科费)/兵志(武科)；APPT 任职不单列层
