# 选举志层库说明（xjz 型 · 正史典志体系列新变体）

> 本文件说明《明史·选举志》知识工程的层方案归属，供后续同书其他志 / 同体例史书复用参考。
> 它是对工厂 `references/layer-library.md`（引导参考板）的**本书定制落地**，不是新增通用层。

## 一、在正史典志体系列中的位置

《明史》四志已实例化（职官/食货/兵志），选举志是第 4 个，四者**同源异形**（同《明史》典志体，对象不同）。层方案命名：

| 型 | 对象 | 关键层 | 与选举志关系 |
|---|---|---|---|
| zgz 型（职官志） | 机构/官职 | L4 定制四维(ORG·RANK·LINE·EVO) + C15 官职层 | 选举志的 REG.agencies 以 `cross_kb` 联动职官志，不重列官职层 |
| shz 型（食货志） | 制度+财货 | REG(★骨架) + L4(QUAN·INST·EVO·FISC) + C16 总账树 | **选举志的直接母型**：REG 骨架、QUAN 数额、制度为纲一脉相承 |
| bz 型（兵志） | 卫所编成+军政 | REG(★骨架) + C17 卫所树 + L4(EVO·QUAN·WEI·REW) + OBJ(薄) | 与选举志同有 REG 骨架 + OBJ 薄层 + QUAN 维度 |
| **xjz 型（选举志）** | 选举/科举/铨选 | **shz 型 + L3 流程(科举三级) + NAM 名录 + FRD 防弊 + L5 事件** | 在 shz 制度骨架上，增本书最强结构信号（科举三级流程、科场弊案叙事） |

**xjz 型 = shz 型（制度为纲）的超集**，差异只在「增三层」：
- **L3 流程**：科举乡→会→殿三级链条清晰（兵志不建 L3、食货不建，选举志必建）。
- **NAM 名录**：一甲题名 / 考官题名 / 进士题名（含人名四元组，高频研究查询）；兵志卫列无人物四元组故不建。
- **FRD 防弊 + L5 事件**：科场弊案（南北榜/冒籍/倩代）是选举史核心叙事，FRD 记手法、L5 记始末，二者互补。

## 二、层清单（xjz 完整型，11 层 + L5）

| 层 | 目录 | 前缀 | 本书角色 |
|---|---|---|---|
| L0 底座 | `_item_registry.json` | — | 卷段拆分 + 指纹库 |
| L1 实体 | `ents/` | `ENT-` | 人物/机构/学校/地名/数量/系统 |
| L2 规则 | `rules/` | `RULE-` | 22 处"著为令/凡/不许/禁"规范性语句 |
| REG 制度 | `regs/` | `REG-` | ★骨架：13 属性 + 选举 token（selection_type/school_type/exam_tier/exam_stage/agencies[cross_kb]/cross_ref/src_loc） |
| L3 流程 | `procs/` | `PROC-` | 科举三级（steps+examiners+sessions+next） |
| L4 四维 | `structs/` | `EVO-/QUAN-/INST-` | EVO 沿革 / QUAN 数额(**region 维度**) / INST 制度类型 |
| C14 时间沿革 | `tmes/` | `TME-` | 纪年事件（洪武→万历 变革链） |
| C9 论说 | `opns/` | `OPN-` | 奏议/主张引语（科举利弊/掣签之议） |
| NAM 名录 | `nams/` | `NAM-` | 一甲/考官/进士/武科题名（四元组） |
| FRD 防弊 | `frds/` | `FRD-` | 冒籍/倩代/怀挟/关节/通榜/其他 |
| OBJ 名物 | `objs/` | `OBJ-` | 八股/贡院/题名碑/武科器械（薄层） |
| L5 事件 | `events/` | `EVT-` | 科场案/制度争议/变革事件（五元组 who/action/what/when/where） |
| 跨层索引 | `_kg_join.json` | — | ≥2 层必建 |

## 三、定制枚举（本书归纳增量，已固化 schemas.md）

- `EXAM_TIERS`：童试 / 科考 / 乡试 / 会试 / 殿试 / **武乡试 / 武会试 / 武殿试** / 未明（试点补武科 tier）。
- `SELECTION_TYPES`：科目 / 贡举 / 荐举 / 铨选。
- `SCHOOL_TYPES`：国学 / 府州县学 / 社学 / 武学 / 宗学 / 其他。
- `REG_CATEGORIES_XJZ`：学校制 / 科举制 / 荐举制 / 铨选制 / 保举 / 考察考满 / 武科 / 其他。
- `QUAN_FORMS`：解额 / 会额 / 监生额 / 教官额 / 生员额 / 未明（**region 必填**）。
- `FRD_TYPES`：冒籍 / 倩代 / 怀挟 / 关节 / 通榜 / 其他。
- `EVT_TYPES_XJZ`：科场案 / 制度争议 / 变革事件 / 其他。

## 四、复用提示

- 同《明史》其他志（如《刑法志》《河渠志》）走本型前，先确认：是否有「可整建制度(REG 骨架)」+「独特结构信号(如流程/名录/弊案)」→ 据此从 shz 型派生并增层。
- 跨书联动约定统一：`REG.agencies[].cross_kb` 指职官志 ORG/OFF；`REG.cross_ref` 指食货志 QUAN（科费/廪给）、兵志武科。
- 护栏（`scripts/_common.py` 四族）全系列共用，实例只填 `LAYER_SPECS`，不重造。
