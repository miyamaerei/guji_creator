# 第 1 项评估：官职层怎么建

> 起因：用户 8 问中 **Q1 上级官职 / Q2 下级官职 / Q3 平级官职** 目前答不了。根因是**官职不是独立实体** —— ORG 树 158 个节点全是机构，官职只是节点上 `posts[]` 的数组元素（无 ID、无父子关系）。L1 实体层已标注 1109 条 `official` 却无索引可用。
> 本文回答「怎么填」。

---

## 一、先问原文有没有「官职—官职」关系

我按 7 类关系词逐词扫了全书 79,493 字：

| 关系型 | 探测式 | 命中 | 判读 |
|---|---|---|---|
| 副贰型 | `佐/贰/为副/副之` | **410** | ✅ 有显式表述 |
| 统率型 | `统/领/督/辖/掌/总理` | 181 | 🟡 多为**机构**对机构 |
| 相参型 | `同知/佥事/并` | 183 | 🟡 多为职名本身 |
| 属官型 | `其属/所属/下辖` | 74 | 🟡 机构对机构 |
| 兼领型 | `兼/带管/领` | 44 | ✅ 官职兼官职 |
| 上级型 | `听于/隶于/统于/属于` | 17 | 🟡 机构对机构 |
| 品级相邻 | `上/下/次/亚 + 官/之` | 33 | 🟡 品级序，非官职序 |

### 关键发现 1：原文有「副贰」这类**官职对官职**的直接表述

```
武十三年罢丞相不设，析中书省之政归六部，以尚书任天下事，侍郎贰之。
                                              ^^^^^^^^^^^^^^
司历、监候佐之。                              ← 钦天监：五官正 → 司历/监候
教授、学正、教谕，掌教诲所属生员，训导佐之。   ← 儒学：教授 → 训导
```

**「A 贰之 / A 佐之」= A 是主官，B 是副贰** —— 这正是一条**官职对官职的上下级边**。

### 关键发现 2：「属官 / 首领官」是建制术语，原文成体系使用

```
掌印       34 处
佥书       32 处
管理       18 处
监工       16 处
首领官      7 处    ← 官制术语：机构的主事之官
属官        7 处
```

### 关键发现 3：**但「郎中之上是侍郎」这类表述，原文一次都没有**

`之上` 仅 5 处、`之下` 2 处，且全是**品级**语境（「三品之上」「七品以下」），**没有一处是官职链**。

**结论：原文提供的是「副贰关系」（谁是主官、谁是副贰），不是「品级链相邻关系」。** 二者不同：侍郎是尚书的副贰，但「郎中之上是侍郎」是**组织包含关系**（郎中属该司，司属该部），不是原文直述的官职相邻。

## 二、三条可选骨架（各有代价）

### 方案 A：**机构链**（官职挂在机构下，用现有 ORG 树）

```
吏部(ORG-501)
├─ 尚书(posts[0])        ← 部级主官
├─ 左侍郎(posts[1])      ← 副贰（原文「侍郎贰之」）
└─ 文选清吏司(ORG-502)
   ├─ 郎中(posts[0])
   └─ 员外郎(posts[1])
```

- **实现**：给 `posts[]` 元素加 `official_id`，`parent_official` = 同机构内 `grade_order` 紧邻的上一个（或机构主官）。
- **代价**：答得了「郎中属哪个机构、同机构还有谁」，**答不了「郎中之上是谁」** —— 因为郎中的上级在**父机构**（吏部），跨节点。
- **覆盖率**：100%（431 条 posts 全在树里）。
- **代价最低**（约 40% 工作量）。

### 方案 B：**品级链**（按 `GRADE_ORDER` 排序成职官序列）

```
正二品 → 尚书
正三品 → 左侍郎 / 右侍郎
正五品 → 郎中
正六品 → 主事
```

- **实现**：全局按 `grade_order` 排序，同品级为一层。
- **问题**：**同品级官职不构成一条链** —— 郎中(吏部·正五品) 与 监正(钦天监·正五品) 无任何关系。且 `posts` 拆分后 228 个唯一官职名，同品级动辄数十个，**"平级"会退化成"同品级列表"** —— 这恰恰是用户当年问 Q3 时不想要的答案（"同品级≠平级"）。
- **覆盖率**：100%，但**信息量低**。
- **不推荐单独使用**。

### 方案 C：**官职树**（新建官职节点，官职间建父子边）

```
尚书 ─┬─ 左侍郎 ─┬─ 郎中 ─┬─ 员外郎 ─┬─ 主事
      └─ 右侍郎 ─┘       └─ ...       
```

- **实现**：新建 `OFFICIALS` 容器，每个 (office, owner) 组合建节点，按 `grade_order` 与机构包含关系建边。
- **优点**：**Q1/Q2/Q3 三问全答**，且是显式的、可查询的树。
- **代价**：**最大**（约 100%）。要定 228 个官职的父子关系，且**原文无直述**时要靠推断（推断依据须写清，否则是为凑结构而编）。
- **风险**：228 个官职 × 机构组合会产生**大量推断边**，污染数据。

## 三、我的建议：**A + C 混合，但 C 只建有原文依据的边**

### 第 1 步：A 打底（必做）

给 427 条 posts 元素加**四个字段**（改 `build_struct.py` 的 `norm_posts`，不动源数据）：

| 字段 | 值来源 | 作用 |
|---|---|---|
| `official_id` | `OFF-<owner简称>-<序号>`，或全局 `OFF-%03d` | 官职唯一主键，激活 1109 条 `official` 实体标注 |
| `parent_official` | 机构主官（该 RANK 记录内 `grade_order` 最小者） | 答 Q1 上级（**同机构内**） |
| `org_path` | ORG 树路径（吏部/文选清吏司） | 答 Q1 上级（**跨机构**，如「郎中→吏部→尚书」） |
| `subordinate_officials` | 反向索引 | 答 Q2 下级 |

**这一步用现有数据即可完成，不需新读原文。**

### 第 2 步：C 只建有据边（增量）

新建 `_officials_ai_NN.py` 源文件，**只收录原文有显式表述的官职边**：

| 边型 | 原文依据 | 例 |
|---|---|---|
| `副贰` | `X贰之` / `X佐之` | 尚书 → 左/右侍郎（"侍郎贰之"）｜五官正 → 司历/监候（"司历、监候佐之"）｜教授/学正/教谕 → 训导（"训导佐之"） |
| `首领` | `首领官` / `掌印` / `佥书` | 机构主官 → 司务（"设主事、司务各四人，为**首领官**"） |
| `兼领` | `兼` / `掌…事` | 提督团营 → 兵部尚书（"命兵部尚书于谦兼领之"） |

**纪律（写进 SKILL.md）**：
- **有显式表述才建边**，无表述不推断 —— 与 §6.8.7「宁缺毋滥」同一原则；
- 每条边必带 `evidence`（原文片段）与 `relation_type`；
- **不按品级相邻自动连边** —— 那是**组织包含关系**（郎中属司、司属部），已在 ORG 树里，重复建边是冗余。

### 第 3 步：三张查询视图（派生，非手写）

| 视图 | 内容 | 答 |
|---|---|---|
| `_views/officials/<official_id>.json` | 该官职的机构 / 品级 / 员额 / **上级** / **下级** / **同机构平级** / 俸禄 / 散阶 | Q1–Q3、Q4、Q6 |
| `_views/officials_flat.csv` | `official_id,office,owner,grade,grade_order,parent_official,salary_ref,selection_route,...` | 一览表 |
| `_views/by_org_official.json` | 机构 → 官职链（主官在前，按 `grade_order`） | 机构编制速览 |

**"平级"定义**（这是 Q3 的关键，必须写死）：
1. **同机构同品级**（首选，如 文选司的郎中 vs 员外郎不同品级 → 不算平级；左侍郎 vs 右侍郎 同品级同机构 → 平级）；
2. **同机构同层级**（如 四清吏司的各郎中 = 平级）；
3. **不跨机构** —— 吏部郎中与户部郎中**不是原文意义上的平级**（虽同品级）。

## 六、附：原文可支撑的官职关系证据（实测样例）

**副贰型（官职对官职，最直接）**
```
析中书省之政归六部，以尚书任天下事，侍郎贰之。        ← 尚书/侍郎
司历、监候佐之。                                      ← 五官正/司历、监候
教授、学正、教谕，掌教诲所属生员，训导佐之。           ← 教授等/训导
```

**首领官型**
```
明初，设主事、司务各四人，为首领官                ← 司务 = 首领官
```

**兼领型（官职兼官职）**
```
景泰元年始设提督团营，命兵部尚书于谦兼领之          ← 提督团营/兵部尚书
```

**掌印/佥书型（内府诸监，成体系）**
```
掌印太监一员，管理、佥书、掌司、写字、监工无定员      ← 34/32 处
```
