## 逐类详评

### ④ 印信 —— ✅ 强烈建议加

**原文证据（礼部条「凡诸司之印信，领其制度」后，一整段约 900 字的完整制度清单）**：

> (内阁，**银印，直纽，方一寸七分，厚六分，玉箸篆文**。)征西、镇朔、平羌、平蛮等将军，**银印，虎纽，方三寸三分，厚九分，柳叶篆文**。宗人府、五军都督府，俱正一品，**银印，三台，方三寸四分，厚一寸**。六部都察院、各都司，俱正二品，**银印，二台，方三寸二分，厚八分**。衍圣公、张真人、中都留守司，俱正二品，各布政司，从二品，**银印，二台，方三寸一分，厚七分**。……顺天、应天二府，俱正三品，**银印，方二寸九分，厚六分五厘**。……各州县儒学、仓库、驿递、闸坝批验所、抽分竹木局、河泊所、织染局、税课局、阴阳学、医学、僧正司、道正司、僧会司、道会司，俱未入流，**铜条记，阔一寸三分，长二寸五分，厚二分一厘**。已上俱**直纽，九叠篆文**。监察御史，**铜印，直纽，有眼，方一寸五分，厚三分，八叠篆文**。总制、总督、巡抚并镇守、公差等官，**铜关防，直纽，阔一寸九分五厘，长二寸九分，厚三分，九叠篆文**。

**为什么加**：
1. 原文给出了**机构 → 印信类型（银印/铜印/铜关防/铜条记）→ 钮式 → 尺寸 → 篆文** 的完整映射，是**可以直接枚举的机构级属性**；
2. 这一句恰好**佐证了用户提到的「差遣官多用关防」**：「总制、总督、巡抚并镇守、公差等官，铜关防」—— 与卷02 的 46 条差遣条目完全对应，可交叉验证；
3. 覆盖率高：该段列举了从内阁到未入流杂职的**全部品级层**，粗估可命中 **~120 个官署机构**。

**字段设计**（ORG 层）：
```python
"seal": {
  "type": "银印",            # 银印/铜印/铜关防/铜条记/金印/镀金印/银印(外国王)/未明
  "knob": "直纽",            # 直纽/虎纽/三台/二台/无
  "size": "方一寸七分",      # 原文原字，不折算
  "thickness": "厚六分",
  "script": "玉箸篆文",      # 玉箸篆文/柳叶篆文/九叠篆文/八叠篆文
  "raw": "内阁，银印，直纽，方一寸七分，厚六分，玉箸篆文。",
  "source_line": 12,
  "confidence": 0.95
}
```
另在 RANK.posts 上不加（印信是**机构**属性，不是职官属性）—— 但可加 `seal_ref` 指向所属机构的印信。

**待建枚举**：`SEAL_TYPES = ["金印","镀金印","银印","铜印","铜关防","铜条记","未明"]`、`SEAL_KNOBS = ["直纽","虎纽","三台","二台","有眼","未明"]`、`SEAL_SCRIPTS = ["玉箸篆文","柳叶篆文","九叠篆文","八叠篆文","未明"]`。

### ③ 考核规则 —— ✅ 建议加

**原文证据（考功司条，完整制度段）**：

> 考功，掌官吏考课、黜陟之事，以赞尚书。凡内外官**给由，三年初考，六年再考，并引请，九年通考**，奏请综其**称职、平常、不称职**而陟黜之。陟无过二等，降无过三等，其甚者黜之、罪之。**京官六年一察，察以巳、亥年**。五品下考察其不职者，降罚有差；四品上**自陈**，去留取旨。**外官三年一朝，朝以辰、戌、丑、未年**。前期移抚、按官，各综其属三年内功过状注考，汇送覆核以定黜陟。**仓场库官一年考，巡检三年考，教官九年考**。府州县官之考，**以地之繁简为差**。吏之考，三、六年满，移验封司拨用。九年满，又试授官。**惟王官及钦天、御用等监官不考**。凡内外官弹章，稽其功过，拟去留以请上裁。

**为什么加**：
- 原文明确给出了**考核周期、考核主体、结果等第、结果去向**四要素，符合用户列举的「由谁考核、考核结果去向」；
- **有差等**：「仓场库官一年考，巡检三年考，教官九年考」→ 可按机构类型填不同周期；
- **有例外**：「惟王官及钦天、御用等监官不考」→ 可填 `exempt: true`。

**字段设计（分两层）**：

ORG 层（机构级考核规定）：
```python
"assessment": {
  "cycle": "三年初考，六年再考，九年通考",   # 原文原字
  "cycle_years": 3,                        # 可解析时填
  "unified_exam": "考满",                   # 考满/考察/朝觐/不考/未明
  "organs": ["吏部考功司"],                 # 考核主体
  "grades": ["称职","平常","不称职"],       # 结果等第
  "results": "陟无过二等，降无过三等",       # 结果去向
  "exempt": false,
  "raw": "...",
  "source_line": 8,
  "confidence": 0.9
}
```

RANK.posts 层（职官级）：加 `assessment_ref`（指向机构）+ 少数职官特有的考核（如「试御史，一年后实授」「理刑进士，半年实授」）。

**待建枚举**：`ASSESS_TYPES = ["考满","考察(京察)","考察(外察/朝觐)","不考","未明"]`、`ASSESS_GRADES = ["称职","平常","不称职","未明"]`。

### ② 选任方式 —— ⚠️ 已有基础，建议扩充

**现状**：`selection_route` 已存在，实测仅填 **14 条**（世官 8 / 流官 6），值域 `["世官","流官","廷推","推升","传升","乞升"]`。

**原文证据（比现值域丰富得多）**：

> 凡选，每岁有**大选**，有**急选**，有**远方选**，有**岁贡就教选**，间有**拣选**，有**举人乞恩选**。……凡升必考满，若员缺当补，不待考满，曰**推升**。类推上一人，单推上二人。三品以上，九卿及佥都御史、祭酒，**廷推**上二人或三人。……有**传升**、**乞升**者，并得执奏。以署职、试职、实授奠年资，……以**荐举**、起废、征召振幽滞，……凡**荫叙**，明初，自一品至七品，皆得荫一子以世其禄。……京官三品以上，考满著绩，始荫一子曰**官生**，其出自特恩者曰**恩生**。

**判定**：用户列的 6 种（科举/荫袭/荐举/纳赀/传奉、特简）中——
- **科举**：原文**无**「某官由科举选」的机构级表述（只有「会试充考试官，殿试充读卷官」这类**主持科举**的职掌，是职能而非选任方式）→ **不加**；
- **荫袭**：原文有 `荫叙` 完整制度 + `世官九等皆有袭职、有替职` → **已有 `succession` 字段，可保留**；
- **荐举**：原文有「以荐举、起废、征召振幽滞」→ **加**；
- **纳赀**：原文**无**（这是明代中后期的实际现象，非《职官志》制度文本）→ **不加**；
- **传奉、特简**：原文有 `传升`（「有传升、乞升者」）与 `特简`（「成祖即位，**特简**解缙、胡广、杨荣等直文渊阁」）→ **加**。

**建议**：`selection_route` 值域扩为
```python
SELECTION_ROUTES = ["世官","流官","廷推","推升","传升","乞升","荐举","特简",
                    "荫叙","官生","恩生","大选","急选","拣选","未明"]
```
并新增 `selection_detail`（原文原字，如「三品以上，九卿及佥都御史、祭酒，廷推上二人或三人」）。

**为什么是「部分」**：绝大多数机构条目原文不声明其官如何选任（这是吏部/兵部的**通用铨法**，不是机构属性），只能对有**显式表述**者填，预计 **~30 条**，其余留白。

### ⑤ 文书权限 —— ⚠️ 建议加（有明确制度表述）

**原文证据一（内阁条「下之达上」清单）**：

> 下之达上，曰**题**，曰**奏**，曰**表**，曰讲章，曰书状，曰文册，曰**揭帖**，曰制对，曰露布，曰译，皆审署申覆而修画焉，平允乃行之。

**原文证据二（通政司条，直接的「能不能上达皇帝」表述）**：

> 通政使，掌受内外章疏敷奏封驳之事。……凡**在外之题本、奏本，在京之奏本，并受之，于早朝汇而进之。有径自封进者则参驳**。午朝则引奏臣民之言事者，**有机密则不时入奏**。有违误则籍而汇请。

**原文证据三（六科条）**：

> 六科，掌侍从、规谏、补阙、拾遗、**稽察六部百司**之事。凡制敕宣行，**大事覆奏，小事署而颁之；有失，封还执奏**。

**原文证据四（兵部「凡除授出自中旨者，必覆奏然后行之」；内阁「诸司奏事，亦不得相关白」）**

**为什么加**：用户问的「题本、奏本、揭帖，能不能直接上达皇帝」在原文里**有直接答案**——内阁「下之达上」列了 10 种文书名目，通政司条明确了「**有径自封进者则参驳**」（即**不得**径自封进，须经通政司），六科有「**封还执奏**」权。

**字段设计**（ORG 层）：
```python
"doc_power": {
  "up_types": ["题","奏","表","揭帖"],       # 可用的上行文书类型
  "down_types": ["诏","诰","制","册文"],     # 下行
  "direct_to_throne": false,                # 能否径自上达
  "veto_power": "封还执奏",                  # 封驳权
  "channel": "通政司",                       # 必经渠道
  "raw": "...",
  "source_line": 52,
  "confidence": 0.85
}
```

**注意**：这是**少数机构**才有的属性（内阁/通政司/六科/都察院/司礼监等），预计 **~45 条**，不可全域填写。

### ⑦ 办公地点 —— ⚠️ 差遣类可填，其余不可

**可分的情况（差遣类，原文有明确「驻」字）**：实测 `驻X` 句式 **95 处**、明确驻地 **152 处**，全部集中在卷02 的总督/巡抚条：

> 三十八年令防秋日**驻宣府**。四十三年，**移驻怀来**。隆庆四年，**移驻阳和**。（总督宣大）
> **开府固原**，防秋**驻花马池**。（总督陕西三边）
> 成化元年，兼巡抚事，**驻梧州**。……改提督为总督，止兼巡抚广西，**驻肇庆**。（总督两广）
> 嘉靖三十三年，以海警，加提督军务，**驻苏州**。万历中，**移驻句容**，已复**驻苏州**。

**不可分的情况（京官机构）**：原文**只有极少数**地点线索 ——「寻改**六科，置于午门外直房**莅事。（六科衙门旧在砖门内尚宝司西。永乐中灾，移午门外东西，每夜一科直宿。）」这类。绝大多数机构（六部、五府、各寺监）**完全不写地址**。用户问的「内廷 / 外朝」区分，原文只在 `内府`/`宦官` 树结构中隐含，**无显式字段级表述**。

**建议**：**只对差遣类填**，字段设计：
```python
"station": "宣府",                    # 当前驻地（一般取最后一次"驻X"）
"station_history": [                  # 沿革，可多年份
  {"era": {"reign":"嘉靖","year":38}, "station":"宣府", "action":"驻"},
  {"era": {"reign":"嘉靖","year":43}, "station":"怀来", "action":"移驻"},
  {"era": {"reign":"隆庆","year":4},  "station":"阳和", "action":"移驻"}
],
"office_location": "未明",             # 内廷/外朝/京城/南京/未明 —— 京官多为"未明"
```
差遣类 **~46 条**可填（正好是卷02 那批）；京官**不加** `office_location`（无证据，强填即臆造）。

### ① 权力类型 —— ❌ 不加

**用户列举**：行政权 / 监察权 / 军政权 / 司法权 / 礼仪 / 文书顾问（内阁） / 宦官内权

**原文证据勘验**：
- 「监察」「弹劾」「纠劾」类词命中 **57** 处，但**全部是职掌陈述句**，例如「其**纠劾**则责之都察院」「司直、清纪郎，掌**弹劾**宫僚，纠举职事」；
- 原文**从未**出现「吏部掌行政权」「都察院掌监察权」这类**分类标签**；
- 原文的表述方式是「**XX，掌……之事/之政令**」（实测 184 处「掌+宾语」），是**职能描述**而不是**权力分类**。

**为什么不加**：
1. 权力类型是**现代政治学的分析框架**，不是原文的自有分类。把它加为字段，等于**用外部标签覆盖原文**；
2. 183 条职掌句若逐条人工判类，会产生大量**边界争议**（兵部的「武选」是行政权还是军政权？吏部的「考功」是行政权还是监察权？），且**无法从原文回溯验证**——违反本项目「一切字段必须有原文依据」的原则；
3. 用户真正想要的「**这个机构管什么**」，现有 `rules` 层（282 条）+ ORG 的 `posts[].duty` 已经承载，且**逐字可溯源**。

**替代方案（若确实需要分类维度）**：可以加一个**可选的、标注为推断**的辅助字段，明确标记非原文：
```python
"power_domain": "监察",     # 推断值，非原文，需人工复核
"_inferred": true,          # 显式标记：此字段为推断，不可作为原文证据
```
但**不建议**默认启用——因为一旦混入，后续无法区分哪些是原文、哪些是推断。**若用户坚持，可加但须全库标记 `_inferred: true`。**

### ⑥ 地理管辖范围 —— ❌ 不加为独立字段（已有承载）

**原文证据（户部十三司条，最典型）**：

> 十三司，**各掌其分省之事**，兼领所分两京、直隶贡赋，及诸司、卫所禄俸，边镇粮饷，并各仓场盐课、钞关。(**浙江司**带管在京羽林右、留守左、龙虎、应天、龙骧、义勇右、康陵七卫，神机营。**江西司**带管在京旗手、金吾前、金吾后、金吾左、济阳五卫。**湖广司**带管国子监、教坊司，在京羽林前、通州、和阳、豹韬、永陵、昭陵六卫，及兴都留守司。……)

**原文证据（都察院十三道条）**：同样格式，「十三司，各掌其分省及兼领所分京府、直隶之刑名」。

**判定**：
- 「**各掌其分省之事**」是**制度性表述**，确实存在；
- **但**：原文紧接着把具体分管省份**以「带管」清单的形式完全展开**了（如「浙江司带管在京羽林右、留守左……七卫」）；
- 这些「带管」清单**已经**在现有数据中由 **ORG 树的 `children[]`** 与 **LINE 边表**承载（`line_type="带管"`，实测 LINE 层共 463 条）；
- 用户列举的「全国 / 一省 / 一道 / 一府一县 / 边镇 / 某专项（漕运、盐政）」，在原文中表现为**不同的表述形态**（户部按**省**分司、都察院按**道**分司、总督按**专项+地域**），**没有统一的分类词**。

**为什么不加独立字段**：
1. **数据已经存在**，只是不在一个叫「地理管辖」的字段里——重复建字段会造成**双份真相**；
2. 「范围层级」（全国/一省/一道/一府县/边镇/专项）这个**分类维度**在原文中**没有对应词**，需人工判定，同 ① 的问题。

**建议（低成本改进）**：在 ORG 层加一个**纯派生的只读视图字段**（不落盘为源数据），供查询：
```python
"scope_summary": {          # 由 children[] + LINE 边自动派生，非手填
  "type": "分省",           # 从机构名/职掌句正则推导：分省/分道/专项/地域/全国
  "items": ["浙江","江西","湖广",...],
  "derived": true
}
```
这样既满足查询需要，又不引入不可验证的人工分类。

## 落地建议（优先级排序）

### 第一优先（证据最硬，收益最大）
1. **`seal`（印信）** —— 建 `SEAL_TYPES`/`SEAL_KNOBS`/`SEAL_SCRIPTS` 三枚举 + ORG 字段 + 从礼部条解析 ~120 机构。**这一条还顺带验证了差遣官用关防的口径。**
2. **`assessment`（考核）** —— 建 `ASSESS_TYPES`/`ASSESS_GRADES` 枚举 + ORG 字段 + 从考功司条解析。

### 第二优先（部分可填，需谨慎）
3. **`doc_power`（文书权限）** —— 建枚举 + ORG 字段，仅填有显式表述者（~45 条）。
4. **`selection_route` 扩充** + `selection_detail` —— 值域从 6 扩到 15。

### 第三优先（限定范围）
5. **`station` + `station_history`（办公地点）** —— **仅差遣类**（~46 条），京官不填。

### 不建议
6. **① 权力类型** —— 除非加 `_inferred: true` 全库标记，否则不建。
7. **⑥ 地理管辖** —— 不建独立字段；若需查询，加**派生只读视图**。
