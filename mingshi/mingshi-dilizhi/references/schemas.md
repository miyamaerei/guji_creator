# 《明史·地理志》实例 schema 规范

> 本文件是写源数据（`scripts\_*_ai_NN.py`）与打包器时的**唯一 schema 参考**。与 `SKILL.md` 冲突时以本文件为准（本文件更细）；与 `_kg_enums.py` 冲突时**必须改枚举文件（VERSION+1）并回填存量**，不得改此处绕过。

## 1. 全局约定

- **ID**：AI 源数据**只写 `slot`（卷内顺序）+ `item_id`**，不写业务 ID；打包器按 `_common.py` 段位表分配 `DLZ-*` ID（单层去重校验）。
- **槽位纪律**：`slot` 是卷内条目序（1 起，不跳跃），`item_id` 形如 `NN-NNN`；每卷源数据的 `item_id` **必须可回填到 `_item_registry.json`**（打包器硬校验，找不到即报 ERR）。
- **原文纪律**：AI 手写数据只写**条号 + 解读**；`original` 原文一概由打包器从指纹库注入，**禁止手抄**（杜绝漂移）。
- **文件命名**：槽位名 / 目录名 / 文件名前缀三处统一**复数**（ents/tmes/geos/evos/hyds/gars/ress）。

## 2. 底座与切分口径

### 2.1 卷映射与行范围

| 02 地理二 | L328 | L330 | L332–L597 | 264 |

| 06 地理六 | L1445 | L1447 | L1449–L1728 | 278 |
| 07 地理七 | L1729 | L1731 | L1733–L2003 | 269 |

### 2.2 条目 = 一行政区

**一行 = 一个政区条目**。不计条的行：`◆…` 章标记 / `◎…` 卷标题 / `○…` 卷目录 / 空行。

**卷首总序判定**：卷01 的 L4–L8 共 5 行（01-001～01-005，以「自黄帝画野置监…」起的《地理志》篇首总论）——**计条保留**（与先例职官志口径一致），执行层标记 `is_virtual: True`，**不生成 GEO 政区树节点**，仅承载 TME/实体/统计。

### 2.3 「短无句号段」判据（卷01 目录行剔除专用）

`split_entries()` 判据（**地理志版，勿沿用职官志版**）：

```
候选段若满足【无句号】且【长度 ≤ 8 字】且【前一候选行以句号结尾】→ 判定为目录行/嵌套标题，剔除
```

- 卷01 L9「京师南京」（4 字、无句号、前一行 L8 总序以句号收）→ 剔除。✅ 已实测
- **「领县N：」防误删**：卷01 政区条目「通州…领县四：」「霸州…领县三：」「昌平州…领县三：」「蓟州…领县四：」及卷02「祁州…领县三：」「安州…领县一：」「易州…领县一：」等**以冒号结尾但无句号**——长度均 > 8 字，**天然不被误删**（判据长度限制的意义就在于此）；若未来改判据必须保留 ≤8 限制。

### 2.4 指纹库 `_item_registry.json`

- key = `NN-NNN`；value = `{ "original": 原文, "norm": 归一化 }`。
- `norm` 规则：① 异体字统一映射（見 `_common.norm_text`：於→于 / 廵→巡 / 緫→总 / 臺→台 / 隸→隶 / 衞→卫 / 裡·裏→里 / 寘→置 …）；② 中文标点统一全角（`，。；：（）「」`）；③ 去除全部空白（半角/全角空格、换行）；④ 全角左括号保留。
- 指纹库由 `build_base.py` 全量重建（幂等）；`--volumes NN` 增量时同样重算该卷并合并写回。

## 3. L1 实体层 schema

源数据 `_ents_ai_NN.py` → `ENT_AI = [ {...}, ... ]`，打包器 `build_ent.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "name": "通惠河",                        # 归一后词形（见 §3.1）
  "alias": ["大通河", "玉河"],             # 原文中的其他词形（可空）
  "type": "water",                          # ENTITY_TYPES
  "count": 2,                               # 本条目内出现次数（≥1）
  "provenance": "领西北至都城东，入白河"    # 判定依据原文片段（可空）
}
```

### 3.1 归一与词形纪律

- **全文本内生**：`name` 词条必须逐字出现在原文；不出现 → 打包器自动剔除并记 GAP。
- 异体字：以 `norm_text` 映射后的词形为准（衞→卫、雲→云、滱→滱保留等）。
- **同名异指**（白河=北京水名 & 陕西水名、卫河、滱水、徐河、漳水等）：一律**分建实体**（宁建勿并），自动入 `同名异指待核清单.csv`（V2），附 `provenance` 区分。
- **同物异名**（卢沟桥/卢沟河→卢沟河、大通河/通惠河→通惠河）：由 `alias` 承载，`alias_index`（词形→ent_id）供反查；**不改标注**。

### 3.2 类型快照（本书适用子集）

`place / water / institution / person / era / time / quantity / work / resource / system / unknown`。
本书不适用语义（official/animal/food…）不写入快照；执行期如必须出现 → V3 决议后 `VERSION+1`。

## 4. TME 时间沿革层 schema

源数据 `_tme_ai_NN.py` → `TME_AI = [...]`，打包器 `build_tme.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "reign": "洪武", "year": 1,              # REIGN_ORDER 存在；year 无则 0
  "era_raw": "洪武元年",                   # 原文纪年字样，必填（溯源）
  "category": "改置",                       # TME_CATEGORIES
  "event": "改为北平府，十月属山东行省",    # 事件摘要（可含多分句）
  "place": "北平府",                        # 涉及地名（归一后）
  "ent_ids": ["ENT-0001"]                   # 关联实体 id（打包器回填校验）
}
```

- **分类枚举** `TME_CATEGORIES`（14）：初置/改置/升秩/降秩/废置/复设/改称/裁并/增置/移治/省入/析置/徙治/未明。
- **纪年纪律**：无纪年（「初」「后」「已而」）→ `reign="未明", year=0, era_raw="未明"`；**禁止**用上下文推断补年（如洪武初=1368 是解释，不是原文数据）。跨年段（「洪武中」「正统末」）→ `era_raw` 记原文字样 + `year=0`。
- `time_key = (REIGN_ORDER[reign], year)` 供时间轴排序；`_views/timeline/` 按政区聚合。

## 5. L4 结构化四维 schema

### 5.1 GEO 政区树（`DLZ-GEO-`）

源数据 `_geo_ai_NN.py` → `GEO_AI = [...]`，打包器 `build_geo.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "name": "顺天府",                        # 归一政区名
  "level": "府",                            # GEO_LEVELS
  "node_type": "政区",                      # GEO_NODES
  "govern": "",                             # TUSI_GOVERN（土司节点填：流官/土官/流土并设；政区留空）
  "tusi_type": "",                          # TUSI_TYPES（土司节点填；政区留空）
  "parent": {"text": "京师", "geo_id": "DLZ-GEO-0001"},   # geo_id 打包器回填
  "children": [],                           # 子节点 geo_id 列表（打包器回填）
  "to_anchor": "京师",                      # 八到锚点名（缺省空）
  "bearing_distance": [                     # 八到拆字段（补强③）
    {"bearing": "北", "distance": 350, "unit": "里", "raw": "北距京师三百五十里"}
  ],
  "quantity": [                             # 编户籍口里
    {"kind": "编户", "amount": 100518, "unit": "户", "year": 1491, "reign": "弘治", "era_raw": "弘治四年"}
  ],
  "note": "领州三，县十七",                  # 原文领属总述
  "is_virtual": False,                      # 卷首总序 = True
  "raw": "……原文由打包器注入……"             # （不手写）
}
```

- **层级**（`GEO_LEVEL_ORDER`）：京师(0) < 布政使司(1) < 府(2) = 直隶州(2) < 属州(3) < 县(4) < 土司/卫/所(5)；树深 ≤6；父级序**非递减**允许同级。
- **领属关系从原文推断**：「领州三，县十七」「领县四」→ children 由打包器按「属X州/县名匹配」登记；州下辖县、府下辖属州/县、布政司下辖府/直隶州/土司节点。
- **土司节点**（补强①）：卷06 广西、卷07 云南贵州——宣慰司/宣抚司/安抚司/长官司/蛮夷长官司/招讨司 建为布政司（或府）下并列节点，`node_type="土司"`，`tusi_type` 取值见枚举；「羁縻」府州等记 `node_type="羁縻"`。**不强行嵌套**（原文多为并列罗列）。
- **八到拆字段**（补强③）：
  - 形态 A「北距府百四十里」→ `bearing="北", distance=140, unit="里", raw=原文`。
  - 形态 B「西南距京师三百五十里」→ `bearing="西南", to_anchor="京师"`。
  - 形态 C「东至磁州界」→ 无距离：`bearing="东"` + `note` 记原文，不造假距离。
  - 距离换算：`cn2int`（百四十→140；有「馀/奇」记 raw 不换算）。
- **数量纪律**：「编户十万五百一十八」→ 100518（万位十进制）；「口六十六万九千三十三」→ 669033；「里五十」→ 里数（单位=里，kind="里"）。年份：无 `弘治四年` 字样者 `year=0`。

### 5.2 EVO 沿革阶段（`DLZ-EVO-`）

源数据 `_evo_ai_NN.py` → `EVO_AI = [...]`，打包器 `build_evo.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "phase": 1,                               # 按原文出现顺序
  "era_raw": "洪武元年", "reign": "洪武", "year": 1,
  "change_type": "改置",                    # EVO_TYPES
  "change": "改为北平府。十月属山东行省。",
  "owner": "顺天府"                         # 政区归属名（归一）
}
```

- 与 TME 分工：EVO = 政区视角**阶段切片**（一条政区多个 phase，串成该政区沿革线）；TME = 时间视角**事件点**（全局时间轴）。同一沿革内容两边各记一次属设计，TME 条目可带 `related_evo`（可选，不强制）。
- `EVO_TYPES`（14）：初置/改置/升州/降县/省入/析置/复置/改隶/移治/改名/废罢/增设/徙治/未明。

### 5.3 HYD 水系河患（`DLZ-HYD-`）

源数据 `_hyd_ai_NN.py` → `HYD_AI = [...]`，打包器 `build_hyd.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "name": "大通河", "alt": "通惠河",
  "type": "河",                              # HYD_TYPES
  "flow": "自玉河出，绕都城东南，下流至高丽庄，入白河",   # 源流（原文直录）
  "anchor": {"item_id": "01-010", "place": "大兴县"},     # 所在政区条目
  "events": [                                # 河患事件（补强④）
    {"kind": "决", "era_raw": "嘉靖三十六年", "place": "卢沟桥", "note": "河决"}
  ]
}
```

- `HYD_TYPES`（10）：河/江/湖/淀/泉/池/溪/海/渠/井。
- `HYD_EVENTS`（7）：决/淤/徙/塞/泛滥/改道/涸。无纪年 → `era_raw="未明"`；有纪年必须 `reign`+`year`（打包器校验 day 不在枚举则报错）。

### 5.4 GAR 卫所关隘（`DLZ-GAR-`）

源数据 `_gar_ai_NN.py` → `GAR_AI = [...]`，打包器 `build_gar.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "name": "天津卫", "type": "卫",           # GAR_TYPES
  "dusi": "直隶",                           # 都司隶属（补强⑤）
  "territorial": "无实土",                  # 实土/无实土/未明（硬约束）
  "established": {"reign": "永乐", "year": 2, "era_raw": "永乐二年十一月置"},
  "place": "静海县北",                       # 所在地（归一政区/方位）
  "ent_ids": ["ENT-0012"]                    # 关联实体（卫所名/驻地，可空）
}
```

- `GAR_TYPES`（8）：卫/守御千户所/巡检司/关/堡/驿/递运所/站。
- `GAR_TERRITORIAL`（3）：**实土 / 无实土 / 未明**。硬约束「卫所有实土者附见，无实土者不载」：接受原文明言的实土/无实土判定；未载者 `未明`，**禁止外推**。
- `GAR_DUSI`（8）：直隶/山东/山西/河南/陕西/四川/湖广/浙江/江西/福建/广东/广西/云南/贵州/辽东/行都司/留守司/未明——以「X都指挥使司」括注或按省属推断，「未明」兜底。

### 5.5 RES 经济资源（`DLZ-RES-`）

源数据 `_res_ai_NN.py` → `RES_AI = [...]`，打包器 `build_res.py`。

```python
{
  "slot": 1, "item_id": "01-010",
  "type": "盐场",                           # RES_TYPES
  "name": "芦台盐场",                        # 资源点名（无专名则复用 type）
  "place": "宝坻县东南",                     # 所在方位（原文）
  "geo_id": "DLZ-GEO-xxxx",                 # 所属政区 GEO id（打包器回填）
  "raw": "有芦台盐场"                        # 原文证据片段（打包器校验逐字命中）
}
```

- `RES_TYPES`（14）：盐场/盐井/盐池/银/金/铜/铁/水银/硃砂/锡/铅/矾/其他/未明。
- 触发形态：「有盐场」「产银」「有铁冶」「出铜」等；政区条名下资源点挂本条目，山川条下资源挂山川条。

## 6. 跨层索引 schema

- `_kg_join.json`：`{ "item_id": {"ents": ["ENT-.."], "tmes": [...], "geos": [...], "evos": [...], "hyds": [...], "gars": [...], "ress": [...], "layer_count": N} }`。
- `_kg_join_flat.csv`：每行一条目，各层 ID 平铺一列（空列 = 该层无记录）。
- `layer_count` 贯通层数（启用 7 层全计；`is_virtual` 条目只计 TME/实体等非 GEO 层）。
- **交付前必查**：0 空条目率（至少有 1 层贯通）+ `layer_count` 分布，不能只信 validate 绿灯。

## 7. 枚举治理

- 单点文件 `scripts/_kg_enums.py`（`VERSION = "1.0"`）。新增/修正枚举：编辑单点文件 → `VERSION += 1` → 全量重跑受影响层 → 回填存量（`registerVersion` 模式）。
- 封闭硬校验：打包器对 `type`/`level`/`category` 等做 `value ∈ ENUM_SET`，不在集内 → 报错列出待决议清单（V3 暂存），**不静默写入**；pending 表 `_data/pending_enum_values.csv`。
- **统计对照基准**：年号纪年 ≈ **2573** 处、卫所巡检 ≈ **926** 处（锁型统计值；正式实测后回填对照表，偏差 >10% 说明口径）。

## 9. 示例条目（试点真实回填，供后续卷参照）

> 5 条真实样例来自试点卷 01/03/07 层产物（validate 后回填，非手工编造）。注意：卷首总序 01-001～01-005 为 `is_virtual: True` 不进政区树；「京师」总述实为 **01-006**（真实 GEO 根节点 DLZ-GEO-0501）。后续卷源数据一律照此格式书写。

### 9.1 京师（01-006）——GEO 根节点 + TME 时间线

- GEO：`DLZ-GEO-0501`，level=京师，children=`["DLZ-GEO-0502"]`（顺天府），quantity 记洪武二十六年编户 334792 户 / 口 1926595，note=「领府八，州三十七，县一百三十六」。
- TME：7 段纪年事件（洪武元年分属河南山东 → 二年置北平行省 → 八年改都卫 → 九年改布政司 → 永乐元年建北京 → 十九年改北京为京师 → 正统六年罢称行在），`reign/year` 已归一。
- 形态要点：**根节点 children 聚合**支撑 Q1（领几府几州几县）；TME 连续纪年支撑 Q4 时间轴。

### 9.2 顺天府（01-007）——GEO 树中段 + EVO 阶段切片

- GEO：`DLZ-GEO-0502`，level=府，parent=`{"text":"京师","geo_id":"DLZ-GEO-0501"}`，children=`["DLZ-GEO-0503"]`（大兴）；quantity 记弘治四年 / 万历六年两朝编户口（如弘治四年户 100518 / 口 669033），支撑 Q10。
