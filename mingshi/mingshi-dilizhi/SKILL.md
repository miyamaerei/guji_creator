3. **八到拆两字段**：`to_anchor`（所至省城/府城/京师名）+ `bearing_distance`（方位 + 距离，如「北距府百四十里」「西南距京师三百五十里」）——原文约 200+ 处「(南/北/东/西/东北/东南/西南/西北)距X里」表述，是「某地在哪里、多远」的可查维度。

## 5. 结构化层方案（L4，启用——本书定制四维）+ RES

| 维度 | ID 前缀 | 本书中的对象 | 说明 |
|---|---|---|---|
| **GEO 政区树** | `DLZ-GEO-` | 直隶/布政司/府/直隶州/属州/县/土司/实土卫所 | **树形**：`children[]` 递归（深度 ≤6），另产出 `_views/geo_tree.json` 全书政区树 |
| **EVO 沿革阶段** | `DLZ-EVO-` | 沿革括注切分出的阶段切片 | 每阶段：纪年 + 变动类型 + 变动内容（与 TME 分工：EVO 为政区视角，TME 为时间视角事件点） |
| **HYD 水系河患** | `DLZ-HYD-` | 河/江/湖/淀/泉/池/海/溪及河患事件 | 水体条目 + `events[]`（决/淤/徙/塞/泛滥/改道/涸，带年代地点） |
| **GAR 卫所关隘** | `DLZ-GAR-` | 卫/守御千户所/巡检司/关/堡/驿/递运所/站 | 含**都司隶属**与**实土/无实土**两字段（补强⑤） |
| **RES 经济资源** | `DLZ-RES-` | 盐场/盐井/盐池/银/金/铜/铁/水银等资源点 | 资源类型 + 所属政区 + 原文证据 |

- **每维封闭枚举**（顶层封闭 + 兜底，详见 `references/schemas.md` §5）：
  - `GEO_LEVELS`（10 值）：京师 / 布政使司 / 府 / 直隶州 / 属州 / 县 / 土司 / 卫 / 所 / 其他·未明
  - `GEO_NODES`：政区 / 土司 / 卫所 / 羁縻 / 未明（与 level 正交）
  - `TUSI_TYPES` + `TUSI_GOVERN`：土司族（补强①）
  - `GEOTOBEARINGS`：北/东北/东/东南/南/西南/西/西北（八到方位）
  - `EVO_TYPES`：初置/改置/升州/降县/省入/析置/复置/改隶/移治/改名/废罢/增设/徙治/未明
  - `HYD_TYPES` + `HYD_EVENTS`：水体类型 + 河患事件（补强④）
  - `GAR_TYPES` + `GAR_TERRITORIAL` + `GAR_DUSI`：卫所类型 + 实土属性 + 都司隶属（补强⑤）
  - `RES_TYPES`：盐场/盐井/盐池/银/金/铜/铁/水银/硃砂/锡/铅/矾/其他/未明（补强②）

- **GEO schema 要点**（树形）：
  ```python
  {
    "slot": 1, "item_id": "01-010",
    "name": "顺天府", "level": "府", "node_type": "政区",
    "govern": "流官",                    # 土司用（TUSI_GOVERN），政区留空
    "tusi_type": "未明",                 # 土司用（TUSI_TYPES），政区留空
    "parent": {"text": "京师", "geo_id": "DLZ-GEO-0001"},
    "children": [],                      # 州/县递归
    "to_anchor": "京师",                 # 八到锚点（补强③）
    "bearing_distance": [{"bearing": "北", "distance": 350, "unit": "里", "raw": "北距京师三百五十里"}],
    "quantity": [{"kind": "编户|口|里", "amount": 50639, "unit": "户", "year": 1491, "reign": "弘治", "era_raw": "弘治四年"}],
    "note": "领州三，县十七",             # 原文领属总述
    "is_virtual": False                  # 卷首总序条目 = True，不进政区树
  }
  ```
  - **树形约束**：`children[]` 递归深度 ≤6（京师→布政司→府→直隶州→属州→县）；父节点 level 序非递减（`GEO_LEVEL_ORDER`）；州下辖县、府下辖属州/县、布政司下辖府/直隶州。
  - **数量解析纪律**：编户口里一律走 `_kg_enums` / `cn2int`（「十万五百一十八」→ 100518；「六万九千五百五十有六」→ 69556）；年份标注须带 `reign` + `year`（弘治四年 = 1491）；无年代记载记「未明」。
  - **八到表述形态**（原文实测）：「北距府四十里」「西南距京师三百五十里」「东至X」「北至X（外为边地）」「距府」「距京师」→ 统一 `bearing_distance[]`；只给「东至XX」不含距离的记 `bearing` 无 `distance`。

- **EVO schema 要点**：
  ```python
  {
    "slot": 1, "item_id": "01-010",
    "phase": 1,
    "era_raw": "洪武元年", "reign": "洪武", "year": 1,
    "change_type": "改置",
    "change": "改为北平府。十月属山东行省。",
    "owner": "顺天府"                     # 政区名（同名多条时与 GEO 关联）
  }
  ```

- **HYD schema 要点**：
  ```python
  {
    "slot": 1, "item_id": "01-010",
    "name": "大通河", "alt": "通惠河",    # 一名/亦曰
    "type": "河",
    "flow": "自玉河出，绕都城东南，下流至高丽庄，入白河",  # 源流
    "anchor": {"item_id": "01-010", "place": "大兴县"},
    "events": [{"kind": "决", "era_raw": "嘉靖三十六年", "place": "卢沟桥", "note": "河决"}]
  }
  ```

- **GAR schema 要点**：
  ```python
  {
    "slot": 1, "item_id": "01-010",
    "name": "天津卫", "type": "卫",
    "dusi": "直隶",                        # 都司隶属（补强⑤）
    "territorial": "无实土",               # 实土/无实土/未明（硬约束）
    "established": {"reign": "永乐", "year": 2, "era_raw": "永乐二年十一月置"},
    "place": "静海县北"                    # 所在地
  }
  ```
  **硬约束执行**：「卫所有实土者附见，无实土者不载」——原文只附见实土卫所；凡条目中被附见的卫所记 `territorial` 按原文（有明证者记实土/无实土，未载者「未明」）；不附见的卫所不补建。

- **RES schema 要点**：
  ```python
  {
    "slot": 1, "item_id": "01-010",
    "type": "盐场", "name": "芦台盐场",
    "place": "宝坻县东南", "geo_id": "DLZ-GEO-xxxx",
    "raw": "有芦台盐场"                    # 原文证据
  }
  ```

## 9. 缺口与边界（执行中持续更新）

| 缺口 | 现状 | 补法 |
|---|---|---|
| 卷首总序 5 条 | 卷01 01-001～01-005 为《地理志》篇首总论（全书统计+疆域综述），计条但不进政区树 | `is_virtual: True`；只承载 TME/实体标注/全书统计引用；不生成 GEO 节点 |
| 八到提取置信度 | 「北距府百四十里」等约 200+ 处，但亦有不含距离的「东至XX」型、含括注的「（外为边地）」型 | `bearing_distance[]` 拆方位与距离；无距离只记方位；括注入 note |
| 河患年代解析 | 「河决」「水淤」多数无显式纪年，需从上下文括注推断 | 无纪年记 `era_raw: "未明"`，不臆断年份；有纪年必须 `reign`+`year` |
| 土司边界 | 云南贵州土司密集，但「宣慰司—安抚司—长官司」从属关系原文多为并列罗列 | GEO 树建土司节点于布政司下（并列），不强行嵌套；羁縻府州记 `node_type: "羁縻"` |
| 同名异指地名 | 「白河」「卫河」「滱水」「徐河」等跨省同名或同源异名 | alias_index 手工映射 + 同名异指待核清单.csv（V2），不自动合并 |
| 卫所实土判定 | 「有实土者附见，无实土者不载」是收录纪律，非逐卫标注 | territorial 按原文记（实土/无实土/未明）；未载者「未明」，**禁止外推** |
| 跨书交叉引用 | 都司卫所/布政司/府州与职官志 ORG、食货志对象同名 | 预留 `cross_book_ref` 字段登记同名对；不强制互链（留后续实例） |
| 统计对照 | 年号纪年≈2573、卫所巡检≈926 为锁型时统计值 | 正式管线实测后回填对照表；偏差 >10% 须说明口径差异 |
| 与《元史志》关系 | 「沿革年月已见《元史志》者不载」——地理志明言不重复元志沿革 | 沿革抽取只收本书明言者；「见元史志」处记 note 不补造 |
