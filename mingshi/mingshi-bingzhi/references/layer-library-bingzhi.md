## 1. bz 型定位（区别于 shz/zgz 型）

| 维度 | 食货志 shz 型 | 职官志 zgz 型 | **兵志 bz 型（本实例）** |
|---|---|---|---|
| 第一骨架 | 制度+数量（历朝沿革叙事） | 机构编制+职掌（隶/统辖关系） | **卫所编成双清单树（C17）** |
| 第二骨架 | 户籍/税制沿革 | 机构沿革 | **军政制度（REG）**：班军/勾军/马政/赏功/训练 |
| 特有层 | L4-QUAN 主表 | NAM 若建 | **C17 卫所树（新层）+ OBJ 名物薄层 + C9 论说（41 处言）** |
| L4 维度 | QUAN 主导 | 无/L3 | EVO / QUAN / **WEI** / **REW**（四维平权） |
| 数量语义 | 田亩/赋税额度 | 员额 | **编成清单数 + 兵额/马额/赏格** |

**建型判据（写死，供评审）**：① 存在「编成清单」完整段落（卫/所/都司连续清单，可切树）→ C17；② 存在臣工奏议引语（「言」「疏」+ 主张）→ C9；③ 名物清单（火器/车船）独立成段 → OBJ。三者齐备 → **bz 型**。

## 3. C17 卫所树完整规格（本实例核心，新增层）

### 3.1 双清单分树（必须，不可合并）

卷66 含**两份不同时点的完整编成清单**：

| 树 | 行段 | 定性 | 层级链 |
|---|---|---|---|
| **旧编成树** `list_ver="old"` | L52–120 | 洪武二十六年定：上十二卫 + 五军都督府属 | 军民类型 → 都督府 → 在京/在外 → 都司/直隶 → 卫/所 |
| **后定编成树** `list_ver="new"` | L122–251 | 成祖后：亲军二十二卫 + 五府属 + **南京卫所** + **羁縻卫所** | 同上 + 土官/宣慰/招讨/长官/数量行 |

两树**同构字段**，仅 `list_ver` 区分；同一卫在两树各建节点（`WEI-0123`/`WEI-0456`），**不合并覆盖**（坑 #54 反义：此处同名异树是合法状态，靠 `list_ver` + `src_loc` 双证据保留）。

### 3.2 层级模型（LEVEL 枚举 10 值）

```
军民类型（上十二卫/亲军二十二卫） → 都督府（左/右/中/前/后军都督府）
 → 在京 / 在外（旧树在外为隐式区，后定树无此层——由父链承载）
 → 都司/直隶/留守司/行都司/宣慰使司  →  卫/所（叶子）
羁縻三段：都司一(奴儿干) → 卫/所/站/地面/寨（数量行子树）
          西北诸部 → 卫六
          西番 → 都指挥使司二/指挥使司一/宣尉使司三/招讨司六/万户府四/千户所十七
```
`LEVEL` 枚举：`军民类型` `府` `在京` `在外` `都司` `直隶` `留守司` `土官` `卫` `所` `数量行`（11 值，含收缩容 `土官`）。

### 3.3 标记文法（已实测；规则引擎只产候选，AI 逐行复核）

| 标记/形态 | 语义 | 处理 |
|---|---|---|
| `◎左军都督府` | 府层级过渡行 | `level=府` 节点 |
| `○在京` / `在京(` | 在京卫所块 | 锚定**行首** `○` 或 `在京(`，**不依赖 ○ 必现**（实测 L57 无 ○） |
| `△浙江都司` / 裸行 `辽东都司` | 都司/直隶行 | 行首 `△` **或**卫列行以卫/都司/宣慰/招讨/长官结尾双判据（实测 △ 非必现） |
| 无标记卫列行 | N 个卫/所名连续无分隔 | 长行切段（3.4）→ 候选卫节点 |
| `(调北京)` `(革)` `(旧《会典》作兀里)` | 卫所级沿革/异名/归属注 | 括注剥离 → 卫节点 `notes[]` + C14 沿革点回指 |
| `已上…`（`已上俱改为亲军`） | **区块级**归属/沿革注 | 挂区块节点 `notes[]`，**不复制**到每个卫 |
| `卫三百八十四` `所二十四` `站七` | 数量专表行 | **QUAN 记录** + 树节点 `count_marker`（list_ver="new" 羁縻子树） |
| 张本行（`初，洪武二十六年定…`） | 清单总起/总账 | 归 REG/总述，不进树；总账段（L121）整段入 C14/QUAN |

### 3.4 长行切段算法（`_weisuo_builder.py` 骨架）

```python
WEI_SUFFIXES = ["卫", "所"]
MIL_UNIT_RE = re.compile(r"[\u4e00-\u9fff]+?(?:卫|所|司|站|寨|地面)(?=[(（]|$|[\u4e00-\u9fff](?=卫|所|司|站|寨|地面))")
# 策略：后缀锚点扫描候选 → 括注归并前词 → WEI_NAME_INDEX 查重 → AI 复核（100%；超长行抽验 20%）
CANDIDATE_RE = r"([\u4e00-\u9fff]+?(?:卫|所|司|站|寨|地面){(?:[^()（）]{0,80})?})"
```
要点：① 括注 `(…)` 紧跟前卫名并入 `note`；② 卫名异体（旂手/旗手）对照 `alias_index`；③ 同名词典 `WEI_NAME_INDEX` 去重靠父链消歧；④ 切段覆盖率（卫/所候选数 vs 原文卫名数）≥95% 为阶段一验收硬指标；⑤ `(已下添设)` 等块注跟随所在区段。

```python
  "children": [],
  "org_binding": {"kind": "五军都督府-左府", "dus": "左军都督府-在京", "bind_note": "后定编成：属左府在京"},
  "notes": ["括注原文，如 调北京 / 后改为屯卫"],
  "tme_ids": [], "quan_id": "",
  "count_marker": "",                 # 数量行节点填写（如 "卫384"），普通卫节点留空

```

### 3.6 跨树对照键与派生视图

- `name_norm`：卫名去「左/右/前/后/中」方位字（`金吾前卫`→`金吾卫`），作 old/new 双树对照键；
- 派生视图 `_views/weis_diff_<都司>.json`：逐都司输出「旧有 / 新有 / 两树皆有」三态（支撑问句 2）；
- **同名卫沿革注不同**（两树皆现 `留守左卫` 但括注略异）→ `src_loc` 双证据保留，不合并（§16-7）。

### 3.7 三子树（后定编成，不混挂，§16-8）

1. **北京五府树**：L124–210（亲军二十二卫 L122–123 为其根上兄弟块）；
2. **南京树**：L211–223 —— `◎南京卫所亲军卫`（L211–212）+ `◎五军都督府属`（L213–223，○左/右/中/前/后府，括注「仍隶北京左府」等）；
3. **羁縻树**：L224–251 —— 奴儿干都司（L225–235，数量行卫384/所24/站7/地面7/寨1）+ 西北诸部（L236–238，卫6）+ 西番（L239–251，都/司/司/司/府/所 六计数行）。

## 4. REG 制度层：13 属性 + 兵志追加 7 token

**继承 13 属性**：name / category / evolution+tme_ids / agencies / targets / levied_items / rates / scope+regions / documents / agents / purposes / abuses / source+source_item_id+evidence。

**追加 7 token**（实测取 7 值，契约标 5）：

| token | 类型 | 说明 | 示例 |
|---|---|---|---|
| `geo_ref` | obj | 地域锚点 | `{"text": "京师", "ent_ids": ["ENT-0301"], "note": "番上地点"}` |
| `num_value` | num | 制度关键数额 | `160000` |
| `num_unit` | str | 数额单位 | `"人"` |
| `num_semantic` | enum | 数额语义（NUM_SEMANTIC 8） | `"岁额"` |
| `src_loc` | str | 精确行定位 | `"卷66-L252"` |
| `cross_ref` | list | 跨库联动 | `[{"kb": "mingshi-zhiguanzhi", "ref": "ORG-505", "note": "兵部"}]` |
| `mil_class` | enum | 军事类别（MIL_CLASS 8） | `"班军"` |

**REG 定制枚举**：MIL_CLASS 8（京营/卫所/班军/边防/海防江防/军伍清理/马政/赏功火器）；NUM_SEMANTIC 8（岁额/原额/见额/折半/定额/加派/无定额/未明）；INST_TYPES_BZ 13（卫所制/京营/班军/勾军/训练/赏功/马政/边防/海防/火器制/车船制/民壮土兵/其他）；REG_STATUS 8（初置/定制/遵行/弊坏/改革/复设/废罢/未明）。

## 5. 其他层 schema/枚举速查（细表均见 `schemas/bz_schemas.json`）

- **C14**：TME_CATEGORIES 13（继承 11 + 定额变更 + 法弊）；`era` 三元组 `{"text","dynasty","reign","year"}`；触发源 = 卷65/67/68 纪年句 + 卷66 括注转写；数量行不建 TME。
- **C9**：OPN_TYPES 6（奏议/疏/建言/论/驳议/引书）；stance 5（褒扬/批评/辨析/陈述/存疑）；准入判据 `len(quote)>=40 ∧ 任一 marker`；OPN_CLAIM_MARKERS 18 = 请/宜/乞/恐/弊/坏/苦/忧/患/不可/非/当/议/驳/论/言其/疏论/极言/+便（王世贞四便）；「从之/报可/帝是其言」进 C14 不进 C9（§16-6）。
- **L2**：RULE_TYPES 7（禁止/义务/允许/程序/时限/处罚/优先级）；只收规范性句（凡/不得/不许/毋得/禁/违者/著为令/定为例/罪之/罚）。
- **OBJ**：OBJ_CLASSES 3（火器/战车/战船）；specs 子字段 material/length/weight/capacity/range/use/mount；origin 三元组 era+initiator+note；名物清单必须整串切分（坑 #55）。
- **L4**：
  - EVO_STAGES 9（初置/定制定型/增改/裁革/复设/变法/弊坏/复原/未明）+ 触发词表；
  - QUAN：form（QUAN_FORMS 6 继承：本色/折色/银/钞/钱/未明）+ origin（QUAN_ORIGINS 兵志 14）+ unit（容量/重量/货币/计数/里程/土地六类）+ scene 解析纪律（约数剔除/量纲前缀合并/None 即错）；
  - WEI（卫所编制）：WEI_UNIT_CLASSES 6（卫/千户所/百户所/总旗/小旗/护卫）；基础数据 L45（5600/1120/112/50/10 人）+ L46（护卫五所编制）；
  - REW（赏功等级）：REW_GRADES 8（奇功/首功/次功/头功牌/齐力牌/实授/署职/赏银）；**五套赏格必须带 `scope` 防区字段**（北边/东北边/番寇苗蛮/倭贼/内地反贼），防混读。
