## 2. 工程侧护栏（打包器骨架，Phase ③ 必接）

> 依据：工厂 `references/error-taxonomy.md`（A/B/G/P 四族）。装置见工厂 `assets/skeletons/packer_skeleton.py`；本实例 `scripts/_common.py` 已复制并填 `LAYER_SPECS`（只列启用层，三元组「目录名/索引槽位名/记录键名」同源）。**改动任何护栏函数后必须重跑 `assets/skeletons/self_test.py`**（坑 #62/#63）。

1. **B 族命名契约**：目录名 / 文件名前缀 / 索引槽位名 / schema 键名四处同源，只用 `LAYER_SPECS` 声明一次；子节点 ID 走 `assign_child_ids()`（派生 `<父ID>#<序号>`，保留已有 id，防双遍历器互覆——坑 #54/#39）。
2. **P 族数值解析（本实例高危）**：`cn2int()` 必须处理**量纲前缀**（一千四十四=1044）、**约数标记全串剔除**（`四百三十馀万束`=4,300,000、`十三万二千馀石`=132,000）、**裸万**（`万`=10000）。返回 `None` 一律当**错误**处理，不得静默当 0（坑 #48/#64）。自检样本必须取**真实原文串**（含约数后缀），不能只测纯数字串。
3. **P 族语域锚定**：判章节/条目语义一律 `SemanticGate` 锚定开头（`startswith`），防正文字形词污染（坑 #47）；卫列切段判「是否都司行」锚定行首。
4. **A 族填充率体检**：每个扩展字段（ERIC 7 token / OBJ 形制字段 / QUAN 各子字段）登记进 `FieldCoverage`；**填充率 0 直接判失败**，排查顺序：① 回填器是否真被 build 调用（坑 #56）→ ② 解析覆盖面是否漏组（复合句/超长行——坑 #55）→ ③ 最后才接受「原文确无」；占位「未明」是合法值，不算填充（坑 #45）。
5. **G 族幂等/原子**：写盘一律 `atomic_write_*()`；分层落盘 `merge_layer()` 增量语义；共享文件 `merge_shared_json()` 永不从空字典重建。
6. **问句验收护栏**：交付前必须跑「目标查询问句逐问实测」（§0.1 十问），输出「能答/半答/答不了」三态表——**ERR=0 只证明层内自洽，不证明能回答问题**（坑 #49/#50）。答不了须分类「原文确无」或「结构缺陷」。

3. **条目切分口径**：`◆【第N章-卷N】` 卷标为一级边界；`◎` 卷内大标题为条目主体；`○` 子目行（如 `○边防海防(江防民壮士兵乡兵)`）或「被正文包围的无句号短行」为子目；正文段随最近子目归属。→ `_extract/<vol>.txt`（预计 33 子目）。
4. **指纹库** `_item_registry.json`：key=`NN-NNN`，value=original/norm；norm 归一规则：异体字（幇→帮、迤逦→逦、酆→邦）、缺字（`〈舟宗〉`→艚？**须保持原文词形，归一另存**）、标点统一。
5. **业务 ID 由打包器自动分配**：AI 源数据只写卷内顺序槽位，不手写业务 ID；打包器按全局序号 `enumerate(records, 1)` + 段位分配（容量 500）——坑 #39；`ENTS` 层 ID 为实体主键，**豁免撞号校验**（同一实体多次出现共用 ID）。
6. **写盘与并行纪律**：写文件一律「临时文件 + rename 落盘」；共享汇总文件增量合并语义（`--volumes` 只重算请求卷）——坑 #12/#14；验证脚本写文件输出，不依赖 stdout——坑 #6。

## 4. L1 实体层

- **ENTITY_TYPES 20 值**（继承基准库，不裁剪）：`person` `official` `institution` `place` `era` `work` `object` `animal` `plant` `food` `doc` `system` `behavior` `punishment` `time` `quantity` `posthumous` `star` `event` `unknown`。
- **本书高频类型**：`institution`（五军都督府/都司/卫/兵部/太仆寺）、`place`（边镇/都司辖地/关隘）、`person`（于谦/戚继光/杨一清）、`object`（火器/车船）、`quantity`（兵额/马数/银两）、`time`（纪年）、`system`（班军/勾军/卫所制）、`doc`（军籍勘合/军单/赏功牌）。
- **词形纪律**（坑 #21/#22 承袭）：
  1. `text` **逐字命中原文**——原文写 `锦衣` 不得写 `锦衣卫`（除非原文全名）；
  2. 卫列行中卫名实体取**完整卫名原字串**（`金吾前卫`），不拆「金吾前+卫」；
  3. 纪年**去朝代前缀**（卷首已领 `永乐三年`，后续 `四年` 只写 `四年`）。
- **种子词典规则**：全文本内生（词条必须出现在原文，否则自动剔除）；归一并列进 `alias_index`。

### 6.3 长行切段算法（`assets/tools/_weisuo_builder.py` 骨架）

卫列行（如 L58 `留守左卫(调北京)镇南卫(调北京)…`）按**卫/所名后缀词典**切段：

```python
WEI_SUFFIXES = ["卫", "所"]                    # 卫名/所名末字
MIL_UNIT_RE = re.compile(r"[\u4e00-\u9fff]+?(?:卫|所|司|站|寨|地面)(?=[(（]|$|[\u4e00-\u9fff](?=卫|所|司|站|寨|地面))")
# 策略：先按后缀锚点扫描切段候选 → 括注归并前词 → 同名词典查重 → AI 复核
CANDIDATE_RE = r"([\u4e00-\u9fff]+?(?:卫|所|司|站|寨|地面){(?:[^()（）]{0,80})?})"
```

**要点**：① 括注 `(…)` 紧贴前卫名，切段后并入前节点 `note`；② 卫名可能含异体（`旂手卫`/`旗手卫`），归一时对照 `alias_index`；③ 超长行（L227 奴儿干卫 384 条仅 1 行）逐段切分后 **AI 抽验 20%**；④ 同名词典 `WEI_NAME_INDEX` 查重（全库同名卫多例，须靠父链消歧——坑 #54）。

## 16. 执行注意（本书特有坑，先读再抽）

1. **卫列切段是最大风险点**：无分隔长行 + 括注紧贴 + 同名异卫 → 规则引擎产候选**必须 AI 复核**，不得直接定稿（坑 #54/#55）。切段覆盖率作为阶段一验收硬指标。
2. **标记文法不一致**（△/○ 有有无无）：一切语义判定锚定**行首/上下文**，不依赖单个标记存在（坑 #47 位置消歧）。
3. **数量解析**：原文既有整文字数（`十六万`）也有约数（`七万五千有奇`/`四百三十馀万束`）与裸量纲（`万`≈万两/万匹），全部走 `cn2int()`，`None` 即报错（坑 #48/#64）。
4. **括注 ≠ 正文**：`(调北京)`/`(革)`/`(旧《会典》作兀里)` 是沿革注不是卫名，剥离后进 C14 / 卫节点 note；**不得**把括注粘进 `name`。
5. **`已上`/数量行是区块级信息**：只挂区块节点，不复制到每个卫（防数据虚增 + 漂移）。
6. **奏议引语与制度站队区分**：C9 只收原文带说话人且 >40 字的声明句；「从之/报可/帝是其言」是决策结果，进 C14/TME，不进 C9。
7. **双树对照**：old/new 卫名归一后对照；**凡两树同一卫名但沿革注不同**（如 `留守左卫(调北京)` 两版皆现但括注略异），以 `src_loc` 保留双证据，不做合并覆盖。
8. **南京卫所/羁縻卫所**：后定编成含南京卫所（L211–223）与羁縻卫所（L224–251，奴儿干都司/西北/西番），**分属三棵子树**（北京五府 / 南京亲军+五府属 / 羁縻），不得混挂。
