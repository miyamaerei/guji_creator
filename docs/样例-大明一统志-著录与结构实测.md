### 3.2 C8 的三条机制性收获（推广时保留）

1. **`availability` 是诚实指数，不是装饰**。这本书 16 A / 9 B / 3 C·D，一眼可见「著录事实里三分之一靠散文抽取」——这正是需要人工抽查的字段清单，比笼统的 confidence=0.85 有用。
2. **D 级必须配 `null_basis`，否则和"忘了填"不可区分**。本书 4 个 null 全带 basis。
3. **卷首自带提要的书，abstract 从 C 降到 B**。凡四库本/带序跋刻本都适用（22 本里至少 `mhd`/`xzl`/`dyz` 同类），省一轮人工撰写。

### 3.3 C8 遗留（小，但要说清）

- `expression.script="繁简混"` 是二值枚举容纳不了的连续事实。现用 `governance` 里补了异体字头实测（寳/宝、東/广）来支撑；建议 C8 把 `script` 明确为"文字形态标签 + 实测注"而非纯度枚举，否则后续书会被迫在「繁/简」里二选一谎报。
- C8 无"文本完整性"字段。本书有 1 个空卷（47）、6,054 个缺字形，这是**著录层就该说的形态事实**，现在只能塞进 C9 的 gap 或知识层的坑表。见 §5-A5。

## 5. 五条契约修正提案（每条：现象 → 实测证据 → 不修的后果 → 建议 → 影响面）

### A1 `recipe.offset_base` —— 偏移基准必须可外置（**新增字段**）

- **现象**：C9 §3.4 规定容器态 `start/end` 指入该 item 的 `original`，S4/S5 也按 `len(original)` 校验。本书做不到。
- **实测证据**：`_item_registry.json` 217 条里 **198 条的 `original` 是占位桩**（空/截断），只有 92 条能定位回原文。偏移若指 `original`，198/217 的段区间无处可指。
- **不修的后果**：要么 spine 直接不产（本书放弃结构），要么像我这次一样**偷偷把偏移指向源 txt**、并给契约加一个未登记字段（`recipe.offset_base`）——后者是野分支，违反 §7 变更通道。
- **建议**：`recipe` 增 `offset_base`（默认 `"registry:original"`，本书取 `"../明一统志.txt"`）+ `offset_base_hash`。S4/S5 改为「按 `offset_base` 取串再校验」。
- **影响面**：底座有桩的书全中（凡 `_item_registry` 为早期薄底座的）。修完这条，S5 重算校验才真正可用而不是被绕过。

### A2 聚合态 `first_item/last_item` 由「必填」降为「必填或显式声明缺口」

- **现象**：§3.4 把 `first_item`/`last_item` 列为聚合态 ✔ 必填；本书 58 个卷节点填不出来。
- **实测证据**：底座 217 条中 **92 条能定位回原文**、**40 条定位不到**、**85 条标题为占位**；`item_id` 前缀去重 **167 个（1–169）**，其中 **79 个 > 90**（根本没有这一卷），只有 **62 条前缀=真实卷号**（符合 §4.3 的 C2 焊接），**30 条前缀与真实卷号漂移**。因此 **59 个聚合节点（58 卷 + 卷首）的 `first_item/last_item` 只能为 null**，`book` 节点的 `last_item` 只能错填成 `05-001`。
- **不修的后果**：要么违约填 null（现状，自检看不见缺口），要么硬凑区间（造假）。
- **建议**：聚合态加 `coverage` ∈ `full | partial | none` + `coverage_basis`（本书填 `none`，basis=「底座 item_id 前缀为分片计数器，非卷号」）。同时 S9 从 WARN 升级为「`coverage=none` 的卷必须逐卷登记原因」。
- **影响面**：所有底座早于 C2 定型的书。这条修完，`juan` 层不再因底座历史包袱而假绿。

### A3 S13 的 kind 次序约束应改为**容器态后置**（放宽聚合级）

- **现象**：S13 要求沿 parent 链 `book<juan<pian<zhang<duan<ju` 非递减。原书的「布政司」标写在**卷题记之下**却统领**多卷**，于是"区域为父、卷为子"这一唯一诚实的父子关系必然写成 `book→pian→juan`——kind 值 2 出现在 1 之前，S13 判倒挂 → region 轴 90 处 WARN。
- **实测证据**：16 个区域标**全部位于其首卷的卷题记之后、同一卷内部**——行 904「明一统志卷十九」→ 行 906「山西布政司」；行 1115→1117（山东）、1330→1332（河南）、1627→1629（陜西）、2378→2380（江西）、3783（福建）同型。也就是说原书用**卷内的一个标题**承担了**跨卷统领**的功能（京师标辖 卷1–5、南京标辖 卷6–18、山西标辖 卷19–21）。我把它建成 `juan` 的父节点（`pian`）就是唯一诚实的表达，而这正是 S13 禁止的方向 → region 轴 90 处倒挂 WARN（primary 轴 0 处）。另注：`中都`(卷7–18) 与 `南京`(卷6–18) 两标区间**重叠**，故 region 轴里 中都 pian 只能有 0 个子节点，其 `first_item/last_item` 也为 null（同 A2）。
- **不修的后果**：要么放弃记录原书真实的"统部"级（丢结构事实），要么永久背着 90 条 WARN（把噪声当常态，闸门失去意义）。
- **建议二选一**：(a) S13 只对"链上出现容器态之后"的节点生效，即约束改为「**聚合级次序自由，容器级（duan/ju）必在最后**」；(b) 在 ladder 里为"统/部/路/司"增设一个低于 `juan` 的 `kind=bu`，并明确它是**可选插入级**。我倾向 (a)：它不需要为每类书加 kind，且守住"容器态是叶子"这条真不变量。
- **影响面**：所有总志/方志类（本书、后世要接的方志）；对蘧编这类"卷即章"的书无影响。

### A4 聚合态需要可选的文本区间（**偏移不该只活在 `evidence` 散文里**）

- **现象**：门（zhang）级在原书有明确题名（顶格「山川」「建置沿革」），也确有一段连续文本；但两态设计里聚合态不许有 `start/end`，容器态的 `title` 恒 null。于是「山川门在原文第几字到第几字」无法既带名又带区间。
- **实测证据**：本书 63 个 `zhang` 节点中 **60 个没有子节点**（只有 3 个门切出了 duan），它们的文本区间我**全部写进了 `evidence` 字符串**（如 `"行 910 门题「建置沿革」顶格，块 [475562,475806)"`）——机器读不到，违反「别只藏在 JSON 里」，也让 S14 的"未覆盖文本必须归属"实际无法执行。
- **不修的后果**：S14 形同虚设；下游要查"某府山川门原文"只能拿正则重扫全文，等于 spine 没交付。
- **建议**：允许 `origin=source` 的聚合态节点携带**可选** `start`/`end`（同一 item 内、块连续、可用 `rule` 重算），并规定「有子容器节点时区间取子的并集，无子时用自身 `start/end`」。字段数不增（复用容器态的两个字段），不违反 §0 铁律 2。
- **影响面**：凡"有题名的一段文字不是叶子"的书——总志的门、会典的项、丛书的小序。

### A5 `rule` 词表缺实用规则；且需要"文本完整性"的登记位

- **现象/证据**：本书实际用到的切分规则是 `entry-bracket`（【】内子条目切分）和 门块切分（顶格门题回溯），契约词表只有 `blank-line | punct-cjk | json-para-align | manual`。其中 `punct-cjk` 在本书**恒不可用**（标点实测 0，§4.1 已禁 `ju`）。另外，空卷47、缺字 6,054、尾部污染 14,198 字这三类**文本完整性事实**在 C8/C9 都没有字段位置，我只能写进报告。
- **建议**：`rule` 改开放枚举 + 工厂 B `structure.json` 为唯一规则真源（C9 只存 id，符合 §5 分工）；C8 增 `expression.text_integrity`（`{missing_juan:[], corrupted_chars:n, tail_contamination:n}`，全部机采 A 级）。
- **影响面**：A 级可全量机采，加字段几乎零成本；不加则每本书的完整性缺口都散落在散文里（正是 §4.2 批评的"散文里再存一份"的病）。

## 6. 条目识别判据实测：为什么"以府题行为锚"不能推广

按 §1 判据跑，**条目锚块 311（建置沿革 256 + 沿革 55），实际检出条题 251**，漏 60。逐卷比对后归因四类，每类都有原文证据（另有一类"跨卷续段"不算漏检，列在表后）：

| 类 | 数量 | 根因 | 原文证据 |
|---|---|---|---|
| (a) **源文件条题行转录缺失** | 4 | 省会府「XX府【四至…】」整行在导出本中丢失，只留下孤立的 `【粮…】` 续行 | 卷22 济南府：行 1117「山东布政司」→ 行 1118 总叙 → 行 1119 `【粮八十五万一千六百石零】` → 行 1120 建置沿革（无题行）；卷32 西安府、卷49 南昌府同型（各有孤粮行）；卷74 福州府连孤粮行都没有 |
| (b) **判据字符集不全（识别侧缺陷）** | 1 + 部分 | 条题带分卷标记「开封府**上**」，尾字不在 `[府州县国司卫下]`；且私用区缺字形 6,054 处把「扬州府」「蒙化府」等题首字切坏 | 行 1334「开封府上【东至直隶鳯阳府宿州界五百一十五里…】」实测存在却被拒；卷12/卷86 条题实测残缺 |
| (c) **同一行粘连多条目 + 异体尾字** | **38**（建置沿革侧） | 边裔卷（云南卷87 / 贵州卷88 / 广西卷85 / 湖广卷66 / 陕西卷37）把「上一门内容 + 下一府条题」粘在同一行，回溯题行时命中的是内容行；另有「衞」异体于「卫」被尾字表拒 | 卷87 行 4740：`土产盐【有井六俱在波弄出】孔雀　小鸡【…】藤永宁府【东至四川行都司…】`——「永宁府」条题在行尾；同类实测 卷87 差 11、卷85 差 5、卷88 差 4、卷87 行 4838「寺观开化寺【…】…腾冲军民指挥使司【…】」、卷88 行 5103「寺观月山寺【…】龙里衞军民指挥使司【…】」、行 5137「毕节衞【…】」（「衞」≠「卫」） |
| (d) **外夷卷尾字判别失效** | **17**（沿革侧，全在卷89–90） | 卷89–90 用 `沿革` 门（55 块），条题多为**不带「国」尾的专名**，同样叠加粘连与异体 | 卷89 行 5192「西蕃」、5199「齐勤防古衞」、5206「察逊衞」、5208「哈宻衞」、5214「和卓」、5230「于阗」；卷90 行 5255「安南」（尾字是「南」不是「国」）——实测全部存在、全部被尾字表 `[府州县国司卫下]` 拒 |
| 合计 | **60 = 43（建置沿革侧）+ 17（沿革侧）** | 建置沿革 256 块 → 检出 213；沿革 55 块 → 检出 38 | (a)4 + (b)1 + (c)38 = 43，(d)17 ✓ |

跨卷续条另计 4 处（不是漏检，是**必须登记归属**的区间）：卷26「开封府上」、卷27「开封府下」、卷33「西安府下」（行 1667，该卷沿革块=0，全卷即卷32 西安府的续段）——卷33 因此是"零条目卷"，spine 里它的 `juan` 节点必须说明"无自有条目，属 卷32 条目之下"。

**结论（设计层，不是修补层）**：条目的**机器锚点是「建置沿革/沿革 门块」，不是「府题行」**。题行是原书的一种排版，会缺（(a) 4 处）、会粘连（(c) 38 处）、会被缺字切坏、会被异体字与不带尾字的专名骗过（(b)(d) 18 处）；门块是本书 311 次稳定出现的结构不变量——**按块锚计数，311 个条目实体 100% 可锚定**。故工厂 B `structure.json` 对地理总志类应写成 `heading_kind: block-anchor`（块锚）：先用块锚定条目边界与文本区间，条题作为该条目的**属性**再用行内切分回抽一次（同一行按 `【` 切开，从右往左取 `[一-龥]{1,14}` 且**不用尾字表做准入判据**，尾字类型只作旁注）。这样 60 处漏检中 **56 处的条题可机读恢复**，(a) 类 4 处条题在源文本里确实不存在（只能 `title=null` + 从「郡名」门或下卷「X下」续条反推，须标 `origin=derived` + 依据）。

**尾字表做准入判据这件事本身不可推广**：本书实测被它拒掉的真条目 18 个（「开封府上」「衞」异体 9 处、「西蕃/和卓/于阗/安南」等不带「国」尾的外夷名）。任何一书一议的字符集，都是下游"全绿但少一条"的坑源。

顺带一条实测：卷89–90 外夷 55 个「沿革」块对应 38 个国条目——**外夷用「沿革」而非「建置沿革」**，若判据只认后者，最后两卷整体不可见。这正是门名词表必须封闭 + 异体/近义全列的原因（实测 28 门种里 `沿革/建置沿革`、`烈女/列女`、`關梁/闗梁` 各为一对）。

**独立源佐证块锚判据**：盘面 `Summary/02_各书产出层.md` 与 `data.js` 记本书外夷为「56 国」——块锚计数 55 与之几乎吻合，题行法只数出 38（缺 18）。也就是说**换用块锚，外夷条目数从 38 升到 55，直接对上另一条已有口径**；这不是理论偏好，是两个源的交叉验证。
