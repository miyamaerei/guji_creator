## 3. 文本预处理规则

- 标点：原文统一全角标点；`£`/`×` 等录入符号不作改动，标注时跳过。
- 缺字：`□` 保留为缺字符号；任何跨 `□` 的标注一律剔除。
- 异体归一表（normalized 字段与预处理文本生效）：

| 原文 | 归一 |
|---|---|
| 筭 | 算 |
| 摽 | 标 |
| 滕 | 誊 |
| 豊 | 丰 |

- 分词：jieba（加载文本内生词表作为用户词典），分词结果见《新官轨范_预处理_分词.txt》。
- 条目偏移：`start/end` 为相对去除 `√` 后的条目正文的字符偏移（0 起、右开）。
- 语境守卫：单字「里」遇前后「面」不标注（如“面里影壁”）；「都」后接“要是来去”不标注。
- 双义处理：数字+「里」一律按数量（距离）标注；“各里/本里/一里十票”等无数字的「里」按地点；该歧义列入人工复核关注项。

## 4. 标注方法

1. **词典层**：文本内生词表最长匹配（多字词优先）。
2. **规则层**：数量（数词+量词、若干/多寡）、时间（时辰、`初X日`、`X日/X月/X年`、`某年月日`）、刑罚（`打/责打/罚/决`+数词）。
3. 重叠消解：长匹配优先；等长按类型优先级 `职官>文书>人物>制度>机构>行为>器物>刑罚>地点>时间>数量`。
4. 泛称词（上司/衙门/人户/小民等）置信度统一 0.70（中置信）；异体归一词条再乘 0.9。

## 5. 置信度公式

```
base：词典精确匹配 0.80–0.92（依类型）；正则规则 0.70–0.80；泛称 0.70
调整：应用异体归一 → ×0.9；含缺字跨段 → 剔除；最终 round(x, 2)
阈值：≥0.85 高置信；0.70–0.84 中置信；<0.70 低置信（进人工复核清单）
```
