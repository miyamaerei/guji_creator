# 《新官轨范》使用报告

> 生成日期：2026-10-09 ｜ 适用读者：后续接手者 / 需要查询这套知识资产的人
> 一句话：一份明代官箴书 txt → 一套可查询、可溯源、可重跑的六层知识库。

---

## 1. 项目定位

本项目为一本书——《新官轨范》（明代官箴书，州县官到任、直日、词讼、粮料等政务规范）——的完整数字化知识工程。从一份抽离 txt 出发，逐层产出机器可读、可交叉引用的结构化知识：

```
txt → EPUB/章节 → 实体标注 → 规则层 → 流程层 → 结构化层 → 事件层 → 跨层索引
```

所有层遵循同一口径：**AI 逐条判定、代码只验缺漏、条粒度、original 指纹注入、每卷独立 JSON + 全局归一、枚举封闭治理、全文本内生词典**。

## 4. 怎么使用

### 4.1 快速查询（不跑代码）
- **一行看全某条**：打开 `_kg_join_flat.csv`，按 item_id（如 `04-002`）过滤 → 该条规则/流程/事件/结构/实体 ID 平铺一列。
- **查实体**：`新官轨范_实体_主键表.json` → `entities[]`（normalized/type/count/first_source/surfaces/ent_id）；`alias_index` 支持"词形 → 实体 ID"反查（如 `官府 → ENT-396`）。
- **查规则**：`新官轨范_规则_ai\归一_汇总.json` → rules[]，字段含 type/modals/condition/subject(含 subject_ent_ids)/prohibited_action/obligation_action/punishment/original/confidence。
- **查事件**：`新官轨范_事件_ai\归一_汇总.json` → events[]，五元组 who(含 who_ent_ids)/action/what/when/where。
- **查流程**：`新官轨范_流程_ai\归一_汇总.json` → processes[]，steps 链 + next + agent(含 agent_ent_ids) + events 引用；04 卷直日看 XGF-P-121 状态机。
- **查结构**：`新官轨范_结构_ai\归一_汇总.json` → ledgers/times/docs/actors/frauds 五数组（均含 item_id、actors 含 ent_ids）。

### 4.2 全文回查（溯源）
任何一条规则/流程/事件/结构的 `original` 字段 = 指纹库原文；`item_id` → `新官轨范_章节\NN_*.xhtml` 对应条目；`derived_rule` → 规则层 XGF-R。

### 4.3 可重跑管线（改了数据后全量重建）
```powershell
# 改实体词典（annotate_新官轨范.py 的 LEX）后：
python annotate_新官轨范.py            # 重标 11 卷 + 归一 + 总报告
python build_ent_keys.py               # 重建主键表 + 回填 ent_id
python build_rules_ai_新官轨范.py      # 规则层（含 subject_ent_ids）
python build_proc_ai_新官轨范.py       # 流程层（含 agent_ent_ids、事件引用）
python build_struct_ai_新官轨范.py     # 结构层（含 item_id、ent_ids）
python build_event_ai_新官轨范.py      # 事件层（含 who_ent_ids）
python build_kg_join.py                # 重建跨层索引（JSON + CSV）
```
每层跑完核对 `验证缺漏清单.txt` 的"问题数：0"与 `归一_汇总.json` 总数。支持 `--volumes "03 04"` 单卷重跑。

### 4.4 扩展指南
- **加实体词条**：`annotate_新官轨范.py` → LEX（词典必须出现在原文，否则自动剔除）→ 重跑管线。新增枚举类型需 `_kg_enums.py` 版本+1 并回填存量。
- **加规则/流程/结构/事件**：对应 `_rules_ai_NN.py` / `_proc_ai_NN.py` / `_struct_ai_NN.py` / `_event_ai_NN.py`，按 schema 编写（original 不手抄，交打包器注入）→ 重跑对应打包器。
- **解读词形 join**（如「把门皂隶」→皂隶）：主键表 `alias_index` 手工加映射（不动标注）。
- **新枚举值**：`_kg_enums.py` 单点修改 + 版本+1，重跑受影响层。

## 5. 关键设计（为什么要这样做）

1. **original 不手抄**：AI 源数据只写条号/解读，打包器从指纹库注入原文 → 杜绝手抄漂移（实测修正 3 处）。
2. **条粒度锚点**：item_id（`NN-NNN`）是所有层的共同主键；derived_rule/events 引用让层间可跳转。
3. **枚举单点治理**：类型/模态/机制全部收进 `_kg_enums.py`，新增必须版本+1 回填存量。
4. **修复并入打包器**：P0 的 item_id/事件引用/ent_id 回填都写进生成器，重跑不丢（实测踩坑后根治）。
5. **跨层索引一行全看**：`layer_count` 字段直接告诉你该条贯通了几层。
