## 2. 契约线（MCP，第 7 本起必做）

```powershell
cd E:\git\ToolBox\guji\tools\book-mcp
python server.py selftest          # 20 项全过
python server.py list              # C1–C7 层清单
python server.py enum --group ENTITY   # 20 值+3 别名（office→official 等）
python server.py enum --group RULE     # 7 值
```
- 枚举值**不照抄**：按本书归纳后落 `_kg_enums.py`（与契约核对一致）。
- 用户点名"用 MCP 处理问题"时：查重/裁决/体检都走 MCP（见 §4/§5）。

## 3. 执行（四段式管线）

```
build_base.py 切分 → _extract\NN_卷.txt + _item_registry.json（指纹库）
   ↓
装填源数据：_src\_ents_ai_NN.py / _rules_ai_NN.py / _struct_ai_NN.py
   ↓
打包：build_ent_keys → build_rules → build_struct → build_kg_join
   ↓
校验：validate_layers.py  → 验收闸门 ERR=0 / GAP=0
```

**执行纪律**（lgs 血泪）：
- 源数据（_src 的 .py）**一次 Write 写全文件**——多次 Write 是整体覆盖不是追加（曾 55→5 条）。
- 写完全部源文件**逐文件条数对账**（期望 vs 磁盘），不一致即拦截，再打包。
- struct 记录必须带维度类型字段（act_type/frd_type/lgr_type/tme_type）且值命中枚举——缺字段/错值会被**静默丢条**。
- 打包参数：`python run_all.py '--volumes=NN'`（**单引号整体传参**，防 01→1 截断）。
- 卷切分：卷首篇目与正文标题同名重复 → **以正文 ○/△ 行为准**，篇目列表不计数。

## 4. 用 MCP 处理问题

| 需求 | 工具 | 命令 |
|---|---|---|
| 跨书查重 | federation-mcp | `fed_search 人名`（如"吕坤"→ lgs:ENT-0001，六书无此人=独立 canonical） |
| conflict 裁决 | federation-mcp / curate | 同名**职官概念**（official 类型）→ `lock` 保持并簇；具体人名同名异人 → `reject` |
| 体检 | kb-mcp | `drift --book xxx`（漂移/库外）/ `sync` / `checklist` |

## 5. 移交 + 联邦库并入

1. **备份**：`kb.sqlite` → `kb.sqlite.bak_YYYYMMDD_<book>`。
2. **存量线**（kb-mcp）：`kb_mcp\registry.py` 登记 book（enum_backend=flat、enum_path=`_kg_enums.py`、globs）；`adapters.py` 按需扩展 `_TYPE_FIELDS`/路径。
3. **联邦线**（kb-federation）：仿 `adapters\lgs_adapter.py` 写本书 adapter（注意 `_layers\<key>\<key>_NN.json` 是**子目录形态**，ent 按 ent_id 跨卷去重）；注册 BOOK_REGISTRY；跑 `load → transform → refs`。
4. **裁决**：`fed_conflicts` 拉清单 → 批量 lock/reject → `replay_overrides` 重放；审计留 `override_log`。
5. **学习回路**：`registry.md` 状态更新；`pending-review` 新值提案。

## 6. 枚举入库（走评审，双写）

新枚举值（如 struct 四维）入库流程：
1. 先入 `pending-review.md`（附证据：条数/分布）。
2. 评审三条件：**跨书复用 + 归并优先 + 用户确认**。
3. 双写：`enum-library.md` 加段 + 顶部版本 +1（如 v5→v6）；`enum-changelog.md` 追加版本条目。缺一即野分支。
4. 入库后复跑 `drift` 验证护栏恢复（struct 曾"无基准 235 条"→ 入库后正常 0.0%）。

## 7. 政学录本书备忘

- 原文已有：`原文\政学录·全文.txt` + `原文\政学录·卷一~五.txt`（每卷拆好）+ `白话文\政学录·全文_白话.txt`。
  → 底座阶段**直接以卷文件为源**（不用再从全文重切；全文作交叉校验）。
- 确认总卷数与条目规模（当前只见卷一~五，实例化时核对是否全）。
- 政书形态（官箴/条规体）→ 层方案大概率同 lgs（L1+L2+L4 四维），但**按本书密度信号定**：先抽样看触发词（不可/不许/务要/限 N 日/簿册状式），再锁层。
- 白话文版仅作对照引用源，不建翻译层（沿用 lgs 口径）。
