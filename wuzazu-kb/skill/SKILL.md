## 1. 执行流程总览

按序执行，每阶段收尾对照工厂 checklists：



```
底座（拆分 + 指纹库） → 卷阅读模式标注 → L1实体 → EVT事件 → REL → NAM → CIT → OBJ → CUS → OPN → MING → APPT → TRL → 跨层整合 → 交付
```

各层 ID 命名空间：ENT- / WZZ-E- / REL- / NAM- / CIT- / OBJ- / CUS- / OPN- / MING- / APPT- / TRL-，全部由打包器自动分配（源数据只写卷内顺序槽位，不手写业务 ID—— 防撞号）。

## 2. 底座（公共地基，先做）



1. 输入文件：`C:\Users\Administrator\Downloads\五杂俎.txt`（用户提供 txt，直接拆分，无转码 / OCR）

2. 章节划分：`00_版本说明与序`（序 3 条）+ `01_天部一` \~ `16_事部四`（每卷一个 XHTML/MD，命名 `NN_卷名.xhtml`）

3. 条目切分：**段落 = 条**（txt 中每个非空非卷标题行为一条）→ `_extract\NN_卷名.txt`（格式 `条N|正文`），预计 1761 条（序 3 + 16 卷 1758）

4. 指纹库 `_item_registry.json`：key=`NN-NNN`（00-001..16-NNN），value=original/norm；norm 归一规则：异体字 / 缺字统一为通行字、标点规范（保留句读）

5. 全部条目建 task 清单（阶段可见、完成可核）

6. 卷概要 `volume_summary.json`：每卷卷名 / 条目数 / 起止 item\_id

## 3. 实体层方案（L1，确认启用）



* 实体类型枚举（**继承基准库 enum-library.md §1.1 规范值快照**；本书用子集 + 兜底 "类型待定"；词形归一 office→official、book→work）：**person 人物 / place 地名 / work 书名（文献）/ official 职官 / era 年号朝代 / object 名物 / animal 动物 / plant 植物 / food 饮食 / unknown 类型待定**；本书新增值走 registerVersion 动态回填（见 §13）

* 种子词典规则：全文本内生（词条必须出现在原文，否则自动剔除）

* 归一规则：异体字归一；一人多名（字 / 号 / 谥）经 alias\_index 映射；复合解读词形（如 "林太守春泽公"→林春泽）手工映射不动标注

* 主键表：ENT-001..N + alias\_index（词形 → ent\_id）

* 每卷 JSON + 全局归一 + 标注总报告

## 11.2 古今翻译层方案（TRL，追加确认启用）



* 全 16 卷 + 序逐条古文 → 现代汉语译文，供理解、检索与图谱注释

* 翻译风格枚举（**继承基准库 §1.13**）：**直译 / 意译 / 注释性翻译**

* schema：trl\_id / item\_id / translation / style / note / confidence / original

## 12. 卷阅读模式（V1）



* 产出 `references/volume-profile.md`：16 卷 + 序的卷标注表（卷 / 主导 / 次要 / 阅读模式 / 判定依据）
