## 5. 方法要点（延续 README 契约）

- **按卷扇出、一卷一次调用**：一卷 11 层一次产完，原文只读一遍；紧凑元组（ent/rel/cit）压缩约 30~40% 输出字符。
- **原文零漂移**：AI 只写条号与解读，`original/norm` 由指纹库注入，验证器逐条比对，漂移即 error。
- **修复并入生成器**：装填期发现的枚举/字段问题一律改统一卷源后重跑构建，不落一次性补丁脚本。
- **增量语义**：`build_all.py --volumes` 按卷重算合并，共享汇总不动其他卷；收尾全量重跑一次为权威口径。
- **双层验证闸门**：每卷 `_mk_vol.py NN --build` 须先通过（validate + validate_join exit=0）再进入下一卷，错误不跨卷级联。
