# 03 各书产出层的数据结构与描述

> 盘点日期：2026-10-14 · 字段名实测自各层成品 JSON 的首条记录（嵌套对象展开一层）。
> 无产出的 4 本（兵志/刑法志/松窗梦语/治谱）不填。

## 〇、全书通用范式（先读这一段）

仓库管线统一「四段式」：底座切条 → 装填解读 → 打包成层 → 整合验证交付。所有层记录共享一套锚点：

- **`item_id`**：条号 `NN-NNN`（卷-序），回链底座。
- **`original` / `norm`**：原文与归一文，由打包器从 `_item_registry.json` 指纹库注入（源数据绝不手抄原文）。
- **`<层>_id`**：层内主键（ID 段位常为 卷号×500+序号，防跨卷撞号）。
- **实体引用**：统一 `{text, *_ent_ids}` 嵌套对象（先写字面，再回填实体主键）。
- **`confidence`**：置信度枚举（high/medium 等）。
- **跨层整合**：`_kg_join.json` + `_kg_join_flat.csv`（一条一行、全层回链）。

成品文件形态三类：
1. **标准型**（客座/五杂俎等）：`_layers/<layer>_NN.json`，顶层 `layer, volume, name, id_prefix, id_field, count, generated_at, builder, records`。
2. **records-only 型**（福惠/平平言/实政录/政学录/宛署）：`_layers/<layer>/<layer>_NN.json`，顶层仅 `records`。
3. **卷对象型**（水东 `data/<layer>/` 顶层 `{volume, records}`，ent 为 `{volume, annotations}`；明史诸志顶层 `{volume, records}`；蘧编 `归一_*.json` 顶层 `{layer, count, records}`）。
