## 6. 评估指标

### 6.1 核心指标定义

| 指标 | 定义 | 当前值 | 目标值 |
|------|------|--------|--------|
| **合并覆盖率** | 参与合并的节点数 / 总节点数 | 3.6% | > 60% |
| **跨书合并率** | 跨书 canonical 数 / 总 canonical 数 | 100% | > 80% |
| **候选召回率** | 生成的候选对数 / 实际应合并的对数 | ~10% | > 80% |
| **引用解析率** | 已解析引用数 / 总引用数 | 10.5% | > 70% |
| **关系传播率** | 关系传播提升的候选数 / 总候选数 | 0% | > 30% |
| **准确率** | 正确合并数 / 总合并数 | N/A | > 90% |
| **召回率** | 正确合并数 / 应合并总数 | N/A | > 80% |

### 6.2 指标计算

#### 合并覆盖率

```python
total_nodes = 1000
nodes_in_canonical = 36
coverage = nodes_in_canonical / total_nodes * 100 = 3.6%
```

#### 跨书合并率

```python
cross_book_canonicals = 17
total_canonicals = 17
cross_book_rate = cross_book_canonicals / total_canonicals * 100 = 100%
```

#### 引用解析率

```python
total_refs = 5950
resolved_refs = 626
resolve_rate = resolved_refs / total_refs * 100 = 10.5%
```

### 6.3 指标分析

**当前状态**：
- ✅ 跨书合并率高（100%）—— 但这是因为只有跨书同名才会被合并
- ❌ 合并覆盖率极低（3.6%）—— 大部分节点未参与合并
- ❌ 候选召回率低（~10%）—— 大量应合并的对未被识别
- ❌ 引用解析率低（10.5%）—— 大量引用无法解析
- ❌ 关系传播率为 0 —— 未利用关系网络

**问题根源**：
1. 仅依赖名字精确匹配，缺少别名/变体识别
2. 未利用关系网络进行匹配
3. 未利用上下文相似度
4. 实体提取不完整（大量引用找不到对应实体）

## 7. 改进方案

### 7.1 短期改进（1-2 周）

1. **实现别名/变体匹配**
   - 从 ent_keys 提取别名
   - 从 original 文本提取括注同位语
   - 预期提升：合并覆盖率 +20%

2. **实现关系网络匹配**
   - 构建关系邻接表
   - 计算关系网络重叠度
   - 预期提升：合并覆盖率 +15%

3. **改进引用解析**
   - 模糊匹配（Levenshtein 距离）
   - 上下文匹配
   - 预期提升：引用解析率 +30%

### 7.2 中期改进（2-4 周）

1. **实现上下文相似度匹配**
   - 从 original 文本提取特征（era/place/office）
   - 计算特征向量相似度
   - 预期提升：合并覆盖率 +10%

2. **实现属性冲突检测**
   - 自动解决互补/同义冲突
   - 人工审核矛盾冲突
   - 预期提升：准确率 +5%

3. **实现分块索引**
   - 按 (type, name_first_char) 分块
   - 预期提升：性能 10x

### 7.3 长期改进（1-2 月）

1. **实现 AI 判定**
   - 用 LLM 对低置信度案例进行判定
   - 构建 ground truth 训练集
   - 预期提升：准确率 +10%

2. **实现权威词表**
   - 从 dlz/myt/mhd/zgz 提取 registry
   - 提供外部权威源
   - 预期提升：召回率 +15%

## 9. 结论

### 9.1 当前状态

- **合并覆盖率极低**（3.6%），说明当前方法严重不足
- **候选召回率低**（~10%），大量应合并的对未被识别
- **引用解析率低**（10.5%），大量引用无法解析
- **关系传播为 0**，未利用关系网络

### 9.2 核心问题

1. **方法单一**：仅依赖名字精确匹配
2. **数据不完整**：实体提取不完整，大量引用找不到对应实体
3. **未利用关系**：关系网络未被用于匹配
4. **未利用上下文**：original 文本的丰富信息未被提取

### 9.3 下一步行动

1. **立即实现**：别名/变体匹配 + 关系网络匹配
2. **短期实现**：上下文相似度匹配 + 属性冲突检测
3. **中期实现**：AI 判定 + 权威词表
4. **长期实现**：完整的 slot-ladder 范式

### 9.4 成功标准

- 合并覆盖率 > 60%
- 准确率 > 90%
- 召回率 > 80%
- 处理速度 > 1000 节点/秒
