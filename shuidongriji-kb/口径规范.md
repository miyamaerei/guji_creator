## 1. 硬性纪律（每卷必守）

1. **实体先查后建**：执行前查 `data\ent\ent_keys.json` 的 `alias_index`（按归一化词形），已存在直接复用 ENT ID，新建才分配；高频实体（御史/尚书/侍郎/指挥/叶盛/三杨等）严禁重复建 ID。
2. **AI 源数据只写条号+解读字段，永不手抄原文**（`original`/`norm` 由打包器从指纹库注入）；未建模条目在源数据注释中如实登记缺口（`"缺口": "NN-NNN 未建模（原因）"`），不强行编造。
3. **枚举封闭**：所有枚举值必须取自 `_kg_enums.py`（APPT_STATUS/ENTITY_TYPES/EVENT_TYPES/REG_TYPES/LIT_TYPES/REL_TYPES/REL_DIRECTIONS/NAM_TYPES/TRL_STYLES）；如确需新增值，`registerVersion+1` 并回溯存量（预期不需要）。
4. **TRL 全量逐条**：本卷条目数 = 翻译数（validate 硬校验为 GAP）；默认 `注释性翻译`·余光中风格（译原意不译原字 / 长句拆并联 / 专名保留+括注 / 忌翻译体公式），对照 translation-style.md 校验清单自查；名录/表格行条目译文保持名录语义并括注今释。
5. **REL 只建文本有直接证据的关系**，宁缺毋滥（direction 单向/双向/未明）。
6. **NAM 表格式名录整体一条 NAM 记录，entries 四元组数组化**（{seq, person, courtesy_name, hometown, office}，无则"未明"）；表格行（一行多人或跨行四元组）按表重组，**勿按行硬拆**；书信中仅提及族谱者 entries 空数组 + evidence 注明。
7. **卷阅读模式决定层优先级**：制度优先 05/06/30、名录优先 17/29、谱牒优先 15/16/18/20、文献优先 19/22/35/13/26（长文卷 14/21/23/24/28/30/37/38 行=条长文）；模式冲突时以 skill `references\volume-profile.md` 与已确认方案为准。
8. **每卷完成后验证本卷 ERR=0**；最终全量 GAP=0。

## 3. 卷执行流程（每卷标准动作）

1. 查 `references\volume-profile.md` 本卷阅读模式（辅以 `_extract\volume_summary.csv` 的 mode_hint）。
2. 查 `data\ent\ent_keys.json` alias_index，建立本卷实体复用/新建清单（先查后建）。
3. 逐层填写 `sources\_<layer>_ai_NN.py`（8 层：ent/appt/event/reg/lit/rel/nam/trl）：模板可先 `python scaffold_volume.py --volumes NN` 生成（幂等，已有文件不覆盖；**禁止 --force 覆盖已填内容**）；填写 DATA 列表，逐条对照 ITEM_LIST 判定。
4. 逐条判定时对照原文（`_extract\items\NN_卷名.txt` 或 `_extract\volumes\NN_卷名.xhtml`；指纹库 original 为准）。
5. 验证：`python run_all.py --volumes NN`（build_base 已修复，单卷复跑安全）→ 读 `reports\验证缺漏清单.txt`，**本卷相关行不得有 ERR**（其他卷 GAP/ERR 属并发或未做卷噪音，忽略；只看汇总 problems=0 与本卷行）。修复至通过。
6. 全书记译文本由 build_trl 自动生成：确认 `data\trl\全书记译本\NN_全书记译本.md` 覆盖本卷全部条目。
7. 汇总回报：产出文件路径、各层 records 数、新增 ENT ID 清单、缺口注释清单、口径问题/建议。

## 4. 层要点（试点确认）

- **ent**：全卷逐条标注实体（text=原文字面，须可在 original 中定位；type 枚举；normalized=归一词形；confidence；source=原文片段）；无实体的条目注释说明。
- **appt**：只抽文本有明确任职句的记录（person/office/institution/when/status/evidence/confidence）；when 未明显式"未明"；status 枚举：现任/致仕/升迁/贬谪/罢黜/兼领/暂代/追赠/未明。
- **event**：五元组 who/action/what/when/where（未明显式"未明"）；type 枚举。
- **reg**：一条目多项制度拆多条记录共享 item_id（name/type/content/institutions/officials）。
- **lit**：title 无篇名则取首句；author 佚名写"未明"（含 author_ent_ids 可空）；type 枚举（诏敕圣旨/碑文/奏议/书启/诗/记…）。
- **rel**：person_a/person_b + relation_type + direction + evidence；只建有直接证据的关系。
- **nam**：name/category/scope/entries/ent_ids/confidence；category 枚举（官员题名/同僚题名/迁谪录/谱牒/题名记/其他）。
- **trl**：translation/style/note/confidence；style 默认"注释性翻译"；note 记难点/异文/专名处理。

## 5. 跨层 ent_ids 约定

- `person_ent_ids / official_ent_ids / ent_ids / who_ent_ids / author_ent_ids / person_a_ent_ids / person_b_ent_ids`：**填实优先**（引用必须已存在于 ent_keys.json，先查后建）；留空数组亦合规（kg_join 按 item_id 链接，不影响可查询性）。试点两卷并存（卷 01 空、卷 17 实），集成阶段统一补链。
- 若验证报"引用未注册实体"ERR：属并发下 ent_keys.json 短暂缺失，先跑全量 `python build_ent_keys.py` 再重跑验证，**不要修改源数据**。

## 6. 并发协作（多片并行）

- 只写本卷文件（`sources\_*_ai_NN.py`）；不删除/覆盖其他卷或底座任何文件。
- `data\ent\ent_keys.json` 为共享累积主键表（加载→合并追加→写回，幂等收敛）；不要手动编辑。
- `data\<layer>\<layer>_summary.json` 为共享概要（最后写入者覆盖；全量重跑收敛，勿依赖其作为唯一产物）。

- 全量收敛由集成方在所有片完成后执行 `python run_all.py`（不带 volumes）——权威重建全部产物并验证 GAP=0。
