## 0. 文档范围与结论先行

本文设计一个 **Vue3 版多书知识阅读器**：一个应用、多本书切换；每本书的知识要素（层）不同，由**配置驱动**自定义页面；复用旧 HTML 阅读器验证过的全部有效交互；为 "实体跨书关联" 预留扩展位。

**三条核心设计决策**（后续全部围绕它们展开）：



1. **数据与视图彻底分离**—— 每本书自带 `book.config.json`（要素声明）+ 数据包；前端不写死任何书的字段。

2. **要素 = 可插拔的渲染管线**—— 公共要素（条目 / 实体 / 事件 / 跨层索引）所有书必配；专用要素（规则 / 流程 / 任职 / 制度 / 文献 / 关系 / 名录 / 翻译）按书启用，每个要素 = 通用列表 / 详情骨架 + 专用视图组件。

3. **跨书关联单独建层**—— 实体不混入任何单书数据；全局实体注册表 + 书内引用表，人工校验闭环确认后写入。

## 2. 旧阅读器有效设计盘点（复用清单）

> 来源：
> `新官轨范_阅读器/阅读器功能与复刻要点.md`
> 。以下设计经验全部复用，实现从原生 JS 换 Vue3 组件化。

### 2.1 复用：数据模型约定（硬复用）



| 约定        | 说明                                     | 复用方式                     |
| --------- | -------------------------------------- | ------------------------ |
| 条粒度 iid   | `章号-序号`（如 `01-001`），全书唯一、可排序，是所有层对齐锚点  | 保留为全局主键                  |
| 实体 span   | 原文偏移 `s/e` + 归一词 + 主键 + 类型 → 原文着色与点击绑定 | 保留；渲染层换成 Vue 组件（着色 span） |
| 跨层索引 join | 条目一行列出各层 ID → 详情 "全层表" 与贯通视图的数据源       | 保留；schema 驱动列名           |
| 书证三件套     | 每层记录带 `original / source / confidence` | 保留；任何自定义层必须声明这三字段        |

### 2.2 复用：交互范式（硬复用）



| 范式                    | 旧实现                                    | Vue3 化                                       |
| --------------------- | -------------------------------------- | -------------------------------------------- |
| 三栏阅读器（目录 / 正文 / 关联概览） | 左目录四级懒加载、中正文覆盖式渲染、右关联卡片                | 三栏布局组件；目录树组件（懒加载卷 / 章→条目）；正文组件（着色 / 高亮）      |
| 面包屑 + 历史回跳            | hash 路由 + crumbTo                      | Vue Router + 全局面包屑 store（Pinia）              |
| 类型化详情页                | 每种内容物专门渲染                              | 详情页 = 通用字段渲染器 + 每层专用块（流程图 / 关系图 / 时间线 / 题名表） |
| 总览列表 + 筛选             | 规则层多级可展开树（6 基类 × 组合、前缀匹配计数）、其余层类型 chip | 筛选树组件与 chip 组件，数据来自层 schema                  |
| 搜索高亮                  | TreeWalker 打 mark                      | 正文渲染时按查询词分词着色                                |
| 事件委托                  | 全局 click 委托 + data-obj/data-id         | Vue 组件事件（原生自带）；保留 "统一跳转入口" 约定                |

### 2.3 复用：已踩坑规避（直接继承为设计约束）



* `file://` 禁 fetch → **数据必须打包进构建产物或 public 静态目录**，运行时不做 fetch（Vue 构建后同样适用）。

* 目录展开态数字 / 字符串比较不一致 → 前端统一数值化比较。

* 覆盖式渲染后残留滚动位置 → 组件切换时显式重置滚动。

* 筛选 "包含语义" 导致计数≠结果数 → **前缀匹配 + 节点子孙累计**，保证 "计数 = 过滤结果数"。

* 大数据量不卡 → 分组懒加载（旧版 GROUPS=5）；Vue 侧用**卷级 chunk 按需加载 + 列表虚拟滚动**。

### 3.3 共同特点与缺失分析（需求 6 的答案）

**两书共同具备**（阅读器公共能力的基础）：



* 条粒度原文底座 + 实体 span 着色 + 事件五元组 + 跨层索引 + 书证三件套 + 搜索溯源。

* 实体 "先查后建" 主键表（alias\_index）—— 两书都有 ENT 主键体系。

**共同特点、但某本书缺失的要素**（按补建价值排序）：



| 缺失要素           | 缺失方    | 现状                               | 设计处置                                                 |
| -------------- | ------ | -------------------------------- | ---------------------------------------------------- |
| 古今翻译（TRL）      | 《新官轨范》 | 官箴书文言，阅读门槛与水东同；旧阅读器无译文           | 阅读器公共能力预留 "翻译视图"；新官如需补建可走知识工程 TRL 层（水东已固化余光中风格规范可复用） |
| 职官任职（APPT）     | 《新官轨范》 | 书中官吏任职表述不少（御史 / 知县 / 布政…），未抽任职履历 | 阅读器任职视图（时间线）为公共组件；新官数据补建后即可启用                        |
| 卷 / 章阅读模式（VOL） | 《新官轨范》 | 11 章主题整齐，需求低于水东 38 卷             | 阅读器 "卷 / 章导读" 视图公共化（有标注则显示，无则折叠）                     |
| 人物关系（REL）      | 《新官轨范》 | 规范书人物关系稀疏，ACT 已覆盖角色职责            | 关系视图为公共组件；新官按需启用                                     |
| 规则 / 流程 / 结构化  | 《水东日记》 | 内容为描述性制度（REG），无 IF-THEN / 流程建模   | 不强补；但 "制度→流程"（如早朝仪节可渲染为步骤序列）列为水东 v2 拓展方向             |
| 跨书实体关联         | 两书都缺   | 两书实体体系独立（12 类 vs 8 类、ID 各自编号）    | **§7 专章设计**（本次核心新增能力）                                |

## 4. 总体架构（Vue3）

### 4.1 技术栈



| 层   | 选型                                    | 用途                           |
| --- | ------------------------------------- | ---------------------------- |
| 框架  | Vue 3 + `<script setup>` + TypeScript | 组件化、类型安全                     |
| 构建  | Vite                                  | 打包静态产物 + 数据目录                |
| 状态  | Pinia                                 | 书上下文（当前书 / 当前层 / 筛选 / 面包屑）   |
| 路由  | Vue Router（history 或 hash，按部署方式选）     | 书架 / 阅读器 / 列表 / 详情 / 搜索 / 跨书 |
| 可视化 | ECharts（graph / timeline / sankey）    | 关系图、任职时间线、流程状态机视图            |
| 表格  | 原生表格 + 虚拟滚动（大列表）                      | 名录题名表、任职表、跨层索引表              |

### 5.2 要素启用的判定（三级）



| 级别        | 说明                       | 例子                                              |
| --------- | ------------------------ | ----------------------------------------------- |
| 公共要素（必配）  | 条目 / 实体 / 事件 / 跨层索引 / 搜索 | 两书全有                                            |
| 声明要素（书配置） | `book.config.json` 声明即启用 | 水东 appt/reg/lit/rel/nam/trl；新官 rule/proc/struct |
| 拓展要素（预留）  | 视图组件已注册、数据缺失时列表显示 "待补建"  | 新官 TRL/APPT（缺失方提示）、水东 proc（v2 拓展）               |

前端不写死要素清单：导航 tab、列表筛选、详情块全部由 `layerSchema` 解析生成。

### 5.3 渲染管线（字段驱动的通用层）



```
LayerSchema（字段声明：key/label/type/enum/视图偏好）
  → 通用列表组件（table / card / tree，按 schema.views.list）
  → 通用详情容器（字段渲染：text / enum-chip / ent-ref / link / 原文块）
  → 专用视图组件（按 schema.views.detail 追加：timeline / graph / flow / roster-table…）
```

新增一本书且要素与现有层同构 → **零代码**；要素全新（如未来 "地点沿革层"）→ 只新增 `components/layers/<layer>/` 一组组件 + 注册 schema。

## 6. 页面设计（需求 3：按书差异化设计）

### 6.1 公共页面（两书共用，继承旧版范式）



| 页面   | 路由                         | 设计要点                                                                             |
| ---- | -------------------------- | -------------------------------------------------------------------------------- |
| 书架   | `#/`                       | 书卡片（书名 / 体裁 / 资产统计 / 启用层徽标 / 最近打开）；切换书 → 全局上下文重置，面包屑清空                           |
| 阅读器  | `#/reader/:book?item=`     | 三栏：左目录（卷 / 章 → 条目，卷级懒加载，标注卷阅读模式图标）、中正文（实体着色、搜索高亮、译文开关）、右关联概览（条目 → 各层卡片；"点击查全层→"） |
| 总览列表 | `#/list/:book?layer=`      | 层 tab 由配置动态生成；筛选 = 规则层类型树（前缀匹配计数）/ 其余类型 chip；大列表虚拟滚动                             |
| 条目详情 | `#/detail/:book/item/:iid` | 原文（着色 + 翻译对照按钮）+ 全层表（join 平铺）+ 书证三件套                                             |
| 实体详情 | `#/detail/:book/ent/:eid`  | 词形 / 别名 / 类型 / 出现条目反查 + 各层关联 + **跨书关联区**（§7）                                     |
| 搜索   | `#/search/:book?q=`        | 书内全文搜索（原文 + 译文 + 各层字段），结果按命中类型分组；支持跨书搜索（可选）                                      |

### 6.1.1 目录组件规格（与旧版四级目录对齐）

> 旧版实测（

### 6.1.2 目录组件交互状态定义（TocTree 状态模型）

> 目标：把旧版 "全局变量 + DOM 类名" 的隐式状态，转为 Vue 显式响应式状态，保证
>
> **状态单一数据源**
>
> （选中项由它所在位置推导，不重复维护）。

**状态模型（Pinia store&#x20;**`useTocStore`**，按书命名空间隔离）：**



```
interface TocState {
  // —— 展开状态 ——
  openVolumes:  Set<string>              // 展开的卷（默认首卷展开）
  openChapters: Set<string>              // 展开的章（水东无"章"层 → 恒空）
  openGroups:   Map<string, number|Set<number>>  // 卷/章 → 当前打开的组；单组模式存 number，多开模式存 Set

  // —— 选中状态（单一数据源：currentItem 为唯一真值，卷/章/组由它推导） ——
  currentItem:  string | null            // 当前条目 item_id（如 "17-002"）
  currentGroup: number | null            // 由 currentItem 推导：grpOfItem(iid)
  currentVol:   string | null            // 由 currentItem 推导

  // —— 定位状态 ——
  pendingScroll: string | null           // 待滚动条目（渲染完成后消费）

  // —— 视图状态 ——
  searchTerm:   string                   // 目录内过滤词（按条目摘要/译文摘要过滤）
  collapsed:    boolean                  // 左栏折叠（移动端/专注模式）
}
```

**状态不变量（守卫，避免旧版 "数字 / 字符串不一致" 类 bug）：**



1. `currentVol / currentGroup` **永远由 currentItem 推导**，不允许独立赋值（`derived = f(iid)` 单一数据源）。

2. 单组模式下：`openGroups` 中每个卷 / 章**至多一个组**；展开新组时自动收起同卷旧组。

3. 选中可见性：`currentItem` 所在组必须 ∈ 展开路径（若切卷导致组未展开，自动补展开）。

4. `iid` 数值化统一 `parseInt(String(iid).slice(3))` 后再参与分组 / 比较（继承旧版教训）。

5. 切换书时整树状态重置（面包屑清空）；切书后记忆不跨书（可选 localStorage 按书 key 持久化展开态）。

**事件与行为（组件对外动作）：**



| 事件                                      | 行为                                                                    | 触发方               |
| --------------------------------------- | --------------------------------------------------------------------- | ----------------- |
| `expandVolume(v)` / `collapseVolume(v)` | 切换卷展开；展开时懒加载该卷 chunk                                                  | 卷行                |
| `expandChapter(ch)`                     | 切换章展开                                                                 | 章行                |
| `selectGroup(ch, g)`                    | 打开该组（同卷收起他组）→ 正文**覆盖式渲染**该组 → 重置滚动                                    | 组行                |
| `selectItem(iid)`                       | 推导卷 / 章 / 组 → 组未渲染则单列渲染 → `pendingScroll` 平滑滚动 → 右栏出条目关联概览            | 条目行 / 正文着色 / 外部跳转 |
| `focusFromOutside(iid)`                 | 外部（搜索结果 / 详情页回跳 / 面包屑）定位条目，复用 selectItem 全链路                          | 搜索 / 面包屑 /join 表  |
| `filterTree(term)`                      | 目录内过滤（摘要 / 译文 / 卷名匹配），命中条目所在卷 / 组自动展开                                 | 目录搜索框             |
| `toggleCollapse()`                      | 左栏折叠 / 展开（list/detail 页自动隐藏，沿用旧版 `body.list-view #toc{display:none}`） | 全局布局              |

**同构点（抽离依据）**：



| 维度   | 目录树（TocTree）           | 筛选树（FilterTree / 规则树） | 卷模式树（水东 VOL）   |
| ---- | ---------------------- | --------------------- | -------------- |

| 展开态  | openVolumes/openGroups | rtOpen                | openKeys       |
| 选中态  | 当前条目（导航）               | 当前筛选值（过滤）             | 当前模式（过滤）       |
| 匹配语义 | 定位到条目                  | **前缀匹配**（子树 = 该前缀全部）  | 前缀匹配（模式→其下全部卷） |
| 点击行为 | 覆盖式渲染正文 + 滚动           | 重渲染列表                 | 重渲染列表          |

**统一组件&#x20;**`TreeNav`**（props 驱动差异）：**

interface TreeNavProps {
  nodes: TreeNode[]          // { key, label, count, children?, leaf?: boolean }
  countMode: 'self'|'descendants'   // 计数：自身 / 子孙累计
  selectMode: 'navigate'|'filter'   // 用途：导航（跳正文） / 筛选（过滤列表）

  renderer: { row: (node) => VNode, badge?: (node) => VNode }  // 行渲染（徽标/tag 注入）
}
// 内部状态统一为：openKeys: Set, selected: string|null；事件统一：toggle / select
```

      "type": "person", "aliases": ["叶盛","叶与中","昆山叶盛"],
      "books": [ { "bookId": "shuidong-riji", "localEid": "ENT-2163", "status": "confirmed" },
                 { "bookId": "xinguan-guifan", "localEid": "ENT-…", "status": "candidate" } ] }

② 书内引用（每书实体主键表不动，仅加"gid"可空字段）
   ent: { "eid": "ENT-2163", "normalized": "叶盛", …, "gid": "GE-0001" | null }

③ 候选关联表（人工校验闭环产物，对应同名异人待核清单）
   candidates: { "pair": ["XGF-ENT-012","SDJ-ENT-2163"],
      "matchFields": { "name": 命中, "hometown": 命中, "office": 未明 },
      "suggest": "同人" | "异人", "status": "pending" }
```

### 7.3 关联流程



```
词形相同/别名命中 → 候选收集（跨书自动匹配：名+字+籍贯+官职+时期 加权）
→ 实体详情页"跨书关联区"展示候选（原因 + 建议）
→ 人工确认（阅读器内确认/驳回，或导入待核清单 CSV）
→ 写入 globalEntities + 各书 ent.gid（版本化记录）
```

### 7.4 跨书实体类型映射（新官 12 类 ↔ 水东 8 类）



| 新官轨范（12 类示例）                                           | 水东日记（8 类）                                                                   | 映射                                                       |
| ------------------------------------------------------ | --------------------------------------------------------------------------- | -------------------------------------------------------- |
| person / official / institution / place / era / work … | person / official / institution / place / era / work / posthumous / unknown | 同名词干直接映射；unknown 兜底；后续在阅读器 `entityLinking.ts` 维护映射表（可配置） |

### 7.5 与用户双库架构（kg\_wf + kg\_ming）衔接



* 当前阅读器数据为文件形态；落库后：


  * `kg_wf`（WorkflowCore 工作流侧）承载跨书关联确认流程（candidates → 审批 → 写回）；

  * `kg_ming`（SqlSugar 图谱侧）承载 globalEntities + 书内引用 + 关系边（person 主表 + 书内引用表）。

* 阅读器数据接口设计为 `DataProvider` 抽象（FileProvider / ApiProvider 两实现），未来切库只换 Provider。
