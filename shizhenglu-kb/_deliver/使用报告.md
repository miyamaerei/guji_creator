> 生成日期：2026-10-12 ｜ 适用读者：后续接手者 / 需要查询这套知识资产的人

## 1. 项目定位

本项目为明·吕坤政书《吕公实政录》（15 卷 / 119 条：明职序·明职引·明职卷一·民务卷二三四·乡甲约卷一至六·风宪约重刊序·风宪约卷一（提刑事宜/人命/盗情/奸情/监禁/听讼/用刑/状式）·风宪约卷二）的数字化知识工程。从 `原文\吕公实政录_原文_全卷合并.txt` 出发，逐层产出机器可读、可交叉引用的结构化知识：

```
原文 TXT → _extract 卷分条 → 实体层(L1) → 规则层(L2) → 结构化四维层(L4: ACT/FRD/LGR/TME) → 跨层索引
```

所有层遵循同一口径：**AI 逐条判定、代码只验缺漏、条粒度、original 指纹注入、每卷独立 JSON + 全局归一、枚举单点治理（C5 `_kg_enums.py`）、全文本内生词典**。

白话文版（`白话文\吕公实政录_白话文_全卷合并.txt`）仅作对照引用源，未建翻译层（用户口径："翻译就不用了…直接引用白话文那版做翻译就行了"）。

## 4. 怎么使用

### 4.1 快速查询（不跑代码）
- **一行看全某条**：打开 `_deliver\kg_join_flat_全量.csv`，按 item_id 过滤（如 `14-002` 人命）→ 该条各层 ID 平铺（rules/structs/ents/layer_count）。
- **查实体**：`_global\ent_keys.json`（normalized → ent_id）；`_global\alias_index.json` 支持"原文词形 → normalized"反查。
- **查规则/结构**：对应层 `_layers\rule\rule_NN.json` / `_layers\struct\struct_NN.json`。

### 4.2 全文回查（溯源）
任何一条记录的 `original` 字段 = 指纹库原文（打包器注入，源数据不手抄）；`item_id` → `_extract` 对应条目；引用字段 → 对应层 ID。

### 4.3 可重跑管线（改了数据后重建）
```powershell
cd E:\git\ToolBox\guji\shizhenglu-kb
python run_all.py '--volumes=15'   # 单卷重跑（PowerShell 必须单引号整体传参，防卷号截断）
python run_all.py                  # 全量重跑（扫描 _src 全部已装填卷，_kg_join 回填 119 条）
# 核对 _validate\验证缺漏清单.txt：ERR=0 / GAP=0
```

### 4.4 扩展指南
- **加实体词条**：在 `_src\_ents_ai_NN.py` 按 schema 写（text 必须原文词形，normalized 归一词形）→ 重跑；新增类型改 `_kg_enums.py`（ENTITY_ACTIVE）。
- **加规则/结构**：`_src\_rules_ai_NN.py` / `_src\_struct_ai_NN.py`（struct 必须含维度类型字段 act_type/frd_type/lgr_type/tme_type，且为枚举值）→ 重跑。
- **解读词形 join**：`_global\alias_index.json` 手工加映射（不动标注）。
- **新枚举值**：`_kg_enums.py` 单点修改 + VERSION+1，双写工厂 `enum-changelog.md`，重跑受影响层。

## 5. 关键设计（为什么要这样做）

1. **original 不手抄**：AI 源数据只写条号/解读，打包器从指纹库注入原文 → 杜绝手抄漂移。
2. **条粒度锚点**：item_id（NN-NNN）是所有层共同主键；引用字段让层间可跳转。
3. **枚举单点治理（C5）**：类型/模态/维度全部收进 `_kg_enums.py`，新增必须 version+1 双写回填。
4. **修复并入打包器**：P0 修复写进生成器/源数据，重跑不丢。
5. **跨层索引一行全看**：layer_count 直接告诉你该条贯通了几层。
6. **一卷一文件**：源数据严格 `_<layer>_ai_NN.py` 单卷文件，多卷不得共用/覆盖（卷09-12 曾踩坑）。
